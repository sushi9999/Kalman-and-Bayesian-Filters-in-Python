# 粒子滤波器（Particle Filters）

## 引言（Motivation）

我们要解决这样一个问题。我们有一些运动的物体需要跟踪。这些物体可能是战斗机和导弹，也可能是球场上正在打板球的人。具体是什么并不重要。我们已经学过的滤波器中，哪一个能处理这个问题？很遗憾，没有一个是理想的。让我们来思考一下这个问题的特点。

* **多模态（multimodal）**：我们希望同时跟踪零个、一个或多个物体。

* **遮挡（occlusions）**：一个物体可能挡住另一个，从而导致一个测量值对应多个物体。

* **非线性行为（nonlinear behavior）**：飞机被风扰动，球以抛物线运动，人会相互碰撞。

* **非线性测量（nonlinear measurements）**：雷达给出的是到目标的距离。要把它转换成 (x, y, z) 坐标需要开平方根，这是非线性的。

* **非高斯噪声（non-Gaussian noise）**：当物体在背景前移动时，计算机视觉可能把背景的一部分误识别为目标。

* **连续（continuous）**：物体的位置和速度（即状态空间）会随时间平滑变化。

* **多变量（multivariate）**：我们希望跟踪多个属性，例如位置、速度、转弯率等等。

* **过程模型未知（unknown process model）**：我们可能并不知道系统的过程模型。

我们前面学过的滤波器，没有一个能很好地同时处理所有这些约束。

* **离散贝叶斯滤波器（Discrete Bayes filter）**：它具备其中大部分属性。它是多模态的，能处理非线性测量，并且可以扩展为处理非线性行为。但它是离散的，且只能处理单变量。

* **卡尔曼滤波器（Kalman filter）**：卡尔曼滤波器为带有高斯噪声的单峰线性系统给出最优估计。但我们这个问题的所有这些前提都不成立。

* **无迹卡尔曼滤波器（Unscented Kalman filter）**：UKF 能处理非线性、连续、多变量问题。然而，它不是多模态的，也不能处理遮挡。它能应付适度非高斯的噪声，但对极度非高斯的分布或极度非线性的问题效果不佳。

* **扩展卡尔曼滤波器（Extended Kalman filter）**：EKF 的优点和限制与 UKF 相同，只是它对强非线性和非高斯噪声更敏感。

右图显示这些点经过下面这组方程之后的结果：

$$\begin{aligned}x&=x+y\\
y &= 0.1x^2 + y^2\end{aligned}$$

使用有限数量的随机采样点来计算结果的方法被称为[*蒙特卡洛*（Monte Carlo, MC）](https://en.wikipedia.org/wiki/Monte_Carlo_method)方法。其思想很简单：生成足够多的点，得到问题的代表性样本，将这些点输入你建模的系统，然后在变换后的点上计算结果。

简单来说，这就是粒子滤波（particle filtering）所做的事情。我们在本书中一直使用的贝叶斯滤波算法被应用到成千上万个粒子上，每个粒子代表系统的一种*可能*状态。我们利用这些粒子的加权统计量从中提取出估计的状态。

## 通用粒子滤波算法（Generic Particle Filter Algorithm）

1. **随机生成大量粒子**

   粒子可以包含位置、朝向，以及任何你想估计的状态变量。每个粒子都有一个权重（概率），表示它与系统真实状态相符的可能性。初始化时给每个粒子相同的权重。

2. **预测下一时刻的粒子状态**

   根据你对真实系统行为的预测来移动这些粒子。

3. **更新（Update）**

   根据测量更新粒子的权重。与测量值匹配得越好的粒子，权重越高；不匹配的粒子权重则较低。

4. **重采样（Resample）**

   丢弃极不可能的粒子，用更可能的粒子的副本来替换它们。

5. **计算估计值**

   可选地，计算粒子集合的加权均值和协方差，得到状态估计。

这个朴素的算法存在一些实际上的困难，我们需要去克服，但总体思路就是这样。我们来看一个例子。我为 UKF 和 EKF 一章中的机器人定位问题写了一个粒子滤波器。这个机器人具有方向控制和速度控制的输入。它的传感器可以测量到可见地标的距离。传感器和控制机制都带有噪声，我们需要跟踪机器人的位置。

第一次迭代之后，粒子在地图上仍然大体随机散布，但你可以看到一些粒子已经聚集在了机器人的位置附近。计算得到的均值已经相当接近机器人的位置。这是因为每个粒子的权重是根据它与测量的匹配程度计算的。机器人在 (1, 1) 附近，所以位于 (1, 1) 附近的粒子由于与测量匹配得很好而拥有较大的权重；远离机器人的粒子与测量不符，因此权重很小。估计位置是粒子位置的加权平均，机器人附近的粒子贡献更大，所以估计相当准确。

经过若干次迭代之后，你可以看到所有粒子都聚集在了机器人的周围。这是由于*重采样*这一步所致。重采样会丢弃极不可能的粒子（权重很低的那些），用更高概率的粒子来代替它们。

我并没有完全说明这*为什么*能行，也没有完整地解释粒子加权和重采样的算法，但你应该能从直觉上理解它。生成一堆随机粒子，让它们大致跟随机器人移动，根据它们与测量的匹配程度赋予权重，只保留那些可能的粒子。这看上去应该可行，事实上也确实可行。

## 通过蒙特卡洛得到概率分布（Probability distributions via Monte Carlo）

假设我们想知道曲线 $y = \mathrm{e}^{\sin(x)}$ 在区间 $[0, \pi]$ 下方的面积。这个面积通过定积分 $\int_0^\pi \mathrm{e}^{\sin(x)}\, \mathrm{d}x$ 来计算。作为练习，去算算这个答案吧，我等你。

如果你是聪明人，就不会接受这个挑战；$\mathrm{e}^{\sin(x)}$ 是不能解析积分的。世界上充满了我们没法积分的方程。例如，考虑计算一个物体的辉度（luminosity）。物体会反射照射在它上面的部分光线，反射出去的一部分光会从其他物体反射回来，再次落到原物体上，从而提高其辉度。这就形成了一个*递归积分*。祝你好运。

然而，使用蒙特卡洛技术来计算积分却非常简单。要求曲线下方的面积，可以构造一个在指定区间内包住曲线的边界框（bounding box）。在框内随机地生成点，然后计算落在曲线下方的点占总点数的比例。例如，如果有 40% 的点落在曲线下方，而边界框的面积是 1，那么曲线下方的面积约为 0.4。当点数趋于无穷时，你可以达到任意精度。在实际中，几千个点就能给出相当准确的结果。

你可以用这种技术对任意复杂的函数进行数值积分。这包括不可积函数和不连续函数。这一技术由 Stanley Ulam 在洛斯阿拉莫斯国家实验室发明，让他能够进行那些无法用纸笔解决的核反应计算。

我们来通过求圆的面积来计算 $\pi$。我们定义一个半径为 1 的圆，并把它放在一个正方形里。正方形的边长是 2，所以面积是 4。我们在框内生成一组均匀分布的随机点，统计有多少落在圆内。圆的面积可以用框的面积乘以圆内点数与总点数的比值来计算。最后，我们知道 $A = \pi r^2$，所以可以得到 $\pi = A / r^2$。

我们先来生成这些点：

```python
N = 20000
pts = uniform(-1, 1, (N, 2))
```

一个点位于圆内当且仅当它到圆心的距离小于等于半径。我们用 `numpy.linalg.norm` 来计算距离，它计算的是向量的模。由于向量从 (0, 0) 出发，调用 `norm` 就能得到点到原点的距离。

```python
dist = np.linalg.norm(pts, axis=1)
```

接下来计算哪些距离满足条件。下面这段代码返回一个布尔数组，当满足 `dist <= 1` 时为 `True`：

```python
in_circle = dist <= 1
```

剩下的就是统计圆内的点数、计算 $\pi$ 并绘制结果。我把它们都放到一个单元里，方便你尝试 `N`（点数）的不同取值。

```python
import matplotlib.pyplot as plt
import numpy as np
from numpy.random import uniform 

N = 20000  # 点的数量
radius = 1.
area = (2*radius)**2

pts = uniform(-1, 1, (N, 2))

# 到 (0,0) 的距离
dist = np.linalg.norm(pts, axis=1)
in_circle = dist <= 1

pts_in_circle = np.count_nonzero(in_circle)
pi = 4 * (pts_in_circle / N)

# 绘制结果
plt.scatter(pts[in_circle,0], pts[in_circle,1], 
            marker=',', edgecolor='k', s=1)
plt.scatter(pts[~in_circle,0], pts[~in_circle,1], 
            marker=',', edgecolor='r', s=1)
plt.axis('equal')

print(f'mean pi(N={N})= {pi:.4f}')
print(f'err  pi(N={N})= {np.pi-pi:.4f}')
```

由此我们认识到：可以用蒙特卡洛方法来计算任意概率分布的概率密度。例如，假设我们有这样一个高斯分布：

```python
from filterpy.stats import plot_gaussian_pdf
plot_gaussian_pdf(mean=2, variance=3);
```

概率密度函数（probability density function, PDF）给出随机变量的取值落在两个值之间的概率。例如，我们可能想知道在上图中 $x$ 落在 0 到 2 之间的概率。这是一个连续函数，所以我们需要通过积分来求曲线下面的面积，因为这块面积就等于该取值范围出现的概率。

$$P[a \le X \le b] = \int_a^b f_X(x) \, dx$$

对高斯分布来说，这个积分很容易计算。但现实生活并没有这么简单。例如下图所示的概率分布，并没有办法用解析式来描述这样一条任意曲线，更别提对它积分了。

```python

```

我们可以用蒙特卡洛方法来计算任意积分。PDF 是用积分来计算的，因此我们也可以用蒙特卡洛方法来计算这条曲线对应的 PDF。

## 粒子滤波器（The Particle Filter）

以上这些把我们引向粒子滤波器。考虑在城市环境中跟踪一个机器人或一辆汽车。为了与之前一致，我会沿用 EKF 和 UKF 一章中的机器人定位问题。在这个问题里，我们跟踪一个具有传感器的机器人，传感器能测量到已知地标的距离和方位角。

粒子滤波器是一族算法。我介绍的是一种比较容易直观理解、也与本书中讨论的问题密切相关的具体形式。这会让其中的某些步骤显得有些"魔法"，因为我没有给出完整的解释。完整解释会在本章后面给出。

借鉴上一节的洞察，我们先创建几千个*粒子*。每个粒子有一个位置，代表机器人在场景中可能位置的一种信念，可能还包含朝向和速度。假设我们对机器人的位置一无所知，我们就把粒子均匀地撒满整个场景。如果你把所有粒子看作一个概率分布，那么粒子较多的位置代表较高的信念，粒子较少的位置代表较低的信念。如果在某个特定位置附近聚集了大量粒子，就意味着我们更确信机器人在那里。

每个粒子需要一个权重，理想情况下它就是该粒子代表机器人真实位置的概率。这个概率通常无法直接计算，因此我们只要求它*正比于*这个概率，因为这是可以计算的。在初始化时，我们没有理由偏好某个粒子，所以对 $N$ 个粒子，我们都赋予 $1/N$ 的权重。这样所有概率之和就等于 1。

粒子和权重共同构成了我们这个问题的*概率分布*。回想一下*离散贝叶斯*那一章。在那一章里，我们把走廊中的位置建模为离散且均匀间隔的格子。这里非常类似，只不过粒子是随机分布在连续空间中，而不是约束在离散位置。在我们这个问题里，机器人可以在某个任意尺寸的平面上移动，其右下角位于 (0, 0)。

为了跟踪机器人，我们需要维护 $x$、$y$ 和朝向这几个状态。我们将 `N` 个粒子保存在一个形状为 `(N, 3)` 的数组中。三列分别按顺序保存 $x$、$y$ 和朝向。

如果你是被动跟踪某物（没有控制输入），那你需要在状态中加入速度，并用速度估计来做预测。维度越高，需要的粒子数会指数级地增加才能形成好的估计，因此我们总是尝试在状态中尽量减少随机变量的数量。

下面这段代码在某个区域上生成均匀分布或高斯分布的粒子：

```python
from numpy.random import uniform

def create_uniform_particles(x_range, y_range, hdg_range, N):
    particles = np.empty((N, 3))
    particles[:, 0] = uniform(x_range[0], x_range[1], size=N)
    particles[:, 1] = uniform(y_range[0], y_range[1], size=N)
    particles[:, 2] = uniform(hdg_range[0], hdg_range[1], size=N)
    particles[:, 2] %= 2 * np.pi
    return particles

def create_gaussian_particles(mean, std, N):
    particles = np.empty((N, 3))
    particles[:, 0] = mean[0] + (randn(N) * std[0])
    particles[:, 1] = mean[1] + (randn(N) * std[1])
    particles[:, 2] = mean[2] + (randn(N) * std[2])
    particles[:, 2] %= 2 * np.pi
    return particles
```

例如：

```python
create_uniform_particles((0,1), (0,1), (0, np.pi*2), 4)
```

### 预测步骤（Predict Step）

贝叶斯算法中的预测步骤利用过程模型（process model）来更新对系统状态的信念。我们要怎么用粒子来做这件事？每个粒子代表机器人的一种可能位置。假设我们向机器人发送一个指令：在转向 0.007 弧度的同时移动 0.1 米。我们可以把每个粒子都按这个量移动。但如果我们这么做，很快就会遇到问题：机器人的控制不是完美的，它不会完全按指令运动。因此我们需要给粒子的运动添加噪声，这样才有合理的机会捕捉到机器人的实际运动。如果你不对系统的不确定性建模，粒子滤波器就无法正确地建模我们对机器人位置的概率分布。

```python
def predict(particles, u, std, dt=1.):
    """ 根据控制输入 u（朝向变化、速度）移动粒子，
    噪声为 Q（朝向变化的标准差，速度的标准差）"""

    N = len(particles)
    # 更新朝向
    particles[:, 2] += u[0] + (randn(N) * std[0])
    particles[:, 2] %= 2 * np.pi

    # 沿着（带噪声的）指令方向移动
    dist = (u[1] * dt) + (randn(N) * std[1])
    particles[:, 0] += np.cos(particles[:, 2]) * dist
    particles[:, 1] += np.sin(particles[:, 2]) * dist
```

### 更新步骤（Update Step）

接下来我们获得一组测量值——每个当前可见的地标对应一个测量。我们应当如何利用这些测量来改变粒子所建模的概率分布？

回想一下**离散贝叶斯**那一章。我们把走廊中的位置建模为离散均匀分布。我们给每个位置分配一个概率，称之为*先验*（prior）。当一个新的测量到来时，我们将该位置当前的概率（*先验*）乘以*似然*（likelihood）——也就是测量与该位置相匹配的可能性：

```python
def update(likelihood, prior):
    posterior = prior * likelihood
    return normalize(posterior)
```

这是下面方程的一种实现：

$$x = \| \mathcal L \bar x \|$$

它本质上是贝叶斯定理的实现：

$$\begin{aligned}P(x \mid z) &= \frac{P(z \mid x)\, P(x)}{P(z)} \\
 &= \frac{\mathtt{likelihood}\times \mathtt{prior}}{\mathtt{normalization}}\end{aligned}$$

我们对粒子做同样的处理。每个粒子有一个位置和一个权重，权重表示该粒子与测量的匹配程度。把权重归一化，使其和为 1，就把它们变成了一个概率分布。距离机器人较近的粒子通常比远处的粒子拥有更高的权重。

```python
def update(particles, weights, z, R, landmarks):
    for i, landmark in enumerate(landmarks):
        distance = np.linalg.norm(particles[:, 0:2] - landmark, axis=1)
        weights *= scipy.stats.norm(distance, R).pdf(z[i])

    weights += 1.e-300      # 避免舍入到 0
    weights /= sum(weights) # 归一化
```

在文献中，这部分算法被称为*序贯重要性采样*（Sequential Importance Sampling, SIS）。计算权重的公式称为*重要性密度*（importance density）。我会在后面一节给出其理论基础。现在我希望它在直觉上是有道理的。如果我们根据粒子与测量的匹配程度来加权，那么这些粒子在融合测量后大致就是系统概率分布的一个良好样本。理论上可以证明这一点。这里的权重就是贝叶斯定理中的*似然*。不同的问题可能需要稍微不同的方式处理这一步，但总体思想是一样的。

### 计算状态估计（Computing the State Estimate）

在大多数应用中，你会希望在每次更新之后得到估计的状态，但滤波器本身只是粒子的集合。假设我们跟踪的是一个对象（即单峰的），就可以将估计的均值计算为粒子的加权值之和：

$$\displaystyle \mu = \frac{1}{N}\sum_{i=1}^N w^ix^i$$

这里我用 $x^i$ 来表示第 $i$ 个粒子。之所以使用上标，是因为我们经常需要用下标来表示时间步，例如第 $k+1$ 时间步的第 $i$ 个粒子可能写成不太美观的 $x^i_{k+1}$。

下面这个函数同时计算粒子的均值和方差：

```python
def estimate(particles, weights):
    """返回加权粒子的均值和方差"""

    pos = particles[:, 0:2]
    mean = np.average(pos, weights=weights, axis=0)
    var  = np.average((pos - mean)**2, weights=weights, axis=0)
    return mean, var
```

如果我们在 $1\times 1$ 的正方形内创建一组均匀分布、权重相等的点，我们会得到一个非常接近正方形中心 (0.5, 0.5) 的均值位置，以及较小的方差。

```python
particles = create_uniform_particles((0,1), (0,1), (0, 5), 1000)
weights = np.array([.25]*1000)
estimate(particles, weights)
```

### 粒子重采样（Particle Resampling）

SIS 算法存在*退化问题*（degeneracy problem）。一开始粒子是均匀分布的、权重相等。机器人附近可能只有少数几个粒子。算法运行下去，任何与测量不匹配的粒子的权重都会变得极低。只有机器人附近的粒子才有可观的权重。我们可能有 5,000 个粒子，但只有 3 个对状态估计有实际贡献！我们说滤波器*退化*（degenerated）了。这个问题通常通过对粒子进行某种形式的*重采样*（resampling）来解决。

权重极小的粒子并不能真正描述机器人的概率分布。重采样算法丢弃这些低概率的粒子，并用高概率的粒子来替代它们。它的做法是复制相对高概率的粒子。这些副本会因预测步骤里加入的噪声而轻微地分散开。结果是大多数粒子都能准确地代表概率分布。

重采样算法有很多种。我们先看一种最简单的：*简单随机重采样*（simple random resampling），又叫*多项式重采样*（multinomial resampling）。它对当前粒子集进行 $N$ 次采样，由这些样本组成一个新的粒子集合。任意一个粒子被选中的概率应当正比于它的权重。

我们用 NumPy 的 `cumsum` 函数实现这一点。`cumsum` 计算数组的累积和。也就是说，第 1 个元素是第 0、1 元素之和；第 2 个元素是第 0、1、2 元素之和，依此类推。然后我们生成 0.0 到 1.0 之间的随机数，并通过二分查找找到与该数最接近的权重：

```python
def simple_resample(particles, weights):
    N = len(particles)
    cumulative_sum = np.cumsum(weights)
    cumulative_sum[-1] = 1. # 避免舍入误差
    indexes = np.searchsorted(cumulative_sum, random(N))

    # 根据索引重采样
    particles[:] = particles[indexes]
    weights.fill(1.0 / N)
```

我们并不在每个时间步都进行重采样。例如，如果你没有收到新的测量值，那你也得不到任何能让重采样受益的信息。我们可以借助所谓的*有效粒子数*（effective N）来决定何时重采样，它近似地度量了那些对概率分布有实际贡献的粒子数。其计算公式为：

$$\hat{N}_\text{eff} = \frac{1}{\sum w^2}$$

可以用如下 Python 实现：

```python
def neff(weights):
    return 1. / np.sum(np.square(weights))
```

如果 $\hat{N}_\text{eff}$ 落到某个阈值以下，就该重采样。一个有用的起点是 $N/2$，但这取决于具体问题。也有可能出现 $\hat{N}_\text{eff} = N$ 的情况，这意味着粒子集塌缩到了一个点（每个粒子的权重都相等）。这或许在理论上不那么"纯"，但发生这种情况时，我会重新生成一个粒子分布，希望由此得到更具多样性的粒子。如果你经常遇到这种情况，可能需要增加粒子数量，或者以其他方式调整滤波器。我们后面会再讨论这个。

## SIR 滤波器——一个完整示例（SIR Filter - A Complete Example）

```python
def resample_from_index(particles, weights, indexes):

    weights.resize(len(particles))
    weights.fill (1.0 / len(weights))
```

第一行假设机器人沿直线运动（`u[0] == 0`），并在 $x$、$y$ 两个轴上各移动 1 单位（`u[1]==1.414`）来预测粒子的位置。转弯误差的标准差为 0.2，距离误差的标准差为 0.05。这一调用返回时，所有粒子都已向前移动，但权重还没有更新，因此暂时不正确。

下一行将测量融合到滤波器中。它不会改变粒子的位置，只会改变它们的权重。回忆一下，粒子的权重是计算它与传感器误差模型对应高斯分布相匹配的概率。粒子离测量距离越远，它就越不可能是一个好的代表。

最后两行检查有效粒子数 ($\hat{N}_\text{eff}$)。如果它跌到 $N/2$ 以下，我们就执行重采样，以尝试确保我们的粒子能够很好地代表实际的概率分布。

现在我们把所有粒子都画出来看看。互动地观看会更有启发性，但这种格式仍能给我们提供有用的信息。我用很浅的绿色和较大的圆点画出了最初的随机点分布，方便把它们与之后用黑色像素画出的迭代粒子区分开来。粒子数量太多会让细节难以看清，所以我把迭代次数限制为 8 次，以便我们放大观察。

```python
seed(2)
run_pf1(N=5000, iters=8, plot_particles=True, 
        xlim=(0,8), ylim=(0,8))
```

从图中看，机器人前两个位置似乎只有几个粒子。这其实并不属实；总共有 5,000 个粒子，只是由于重采样，大多数都是相互的副本。原因在于传感器对应的高斯分布非常窄。这种现象被称为*样本贫化*（sample impoverishment），可能导致滤波器发散。我会在下面详细讨论它。我们先来看 $x=2$ 这一步，可以看到粒子已经稍微分散了一些。这种分散来自运动模型的噪声。所有粒子都根据控制输入 `u` 向前推进，但每个粒子上都加了与机器人控制机制误差成比例的噪声。到了第三步，粒子已经分散到能在机器人周围形成一个像样的"粒子云"。

粒子云的形状是一个椭圆。这并非偶然。传感器和机器人控制都被建模为高斯，因此系统的概率分布也是高斯的。粒子滤波器是对概率分布的采样，所以"云"应当是椭圆形的。

需要重要地认识到：粒子滤波算法*并不要求*传感器或系统是高斯的或线性的。因为我们用粒子云来表示概率分布，所以可以处理任何概率分布以及强非线性问题。概率模型中可以有不连续点和硬性限制。

### 传感器误差对滤波器的影响（Effect of Sensor Errors on the Filter）

滤波器在最初几次迭代中产生了许多重复的粒子。这之所以发生，是因为传感器模型是高斯的，且我们给它指定了一个很小的标准差 $\sigma=0.1$。这一开始让人觉得反直觉。卡尔曼滤波器在噪声更小时表现更好，可粒子滤波器反倒可能更差。

我们可以推理一下为什么会这样。如果 $\sigma = 0.1$，机器人在 (1, 1)，而某个粒子在 (2, 2)，那么这个粒子距离机器人有 14 个标准差。这给了它接近 0 的概率。它对均值估计毫无贡献，并且在重采样后几乎不可能存活。如果 $\sigma = 1.4$，那么这个粒子只在 $1\sigma$ 之外，从而会对均值估计有所贡献，并且在重采样时很可能被复制一次或多次。

理解这一点*非常重要*——一个非常精确的传感器可能会导致滤波器表现不佳，因为很少有粒子是该概率分布的良好样本。我们有几种修补方法。第一种是人为地增大传感器噪声的标准差，让粒子滤波器接受更多点作为与机器人概率分布相匹配。这并不是最优的，因为有些被接受的点其实匹配得很差。真正的问题在于：生成的点不够多，以至于机器人附近的点不足。增加 `N` 通常能修复这个问题。这一选择并非没有代价，粒子数的显著增加会大幅增加计算时间。尽管如此，我们还是来看看用 100,000 个粒子的结果。

```python
seed(2) 
run_pf1(N=100000, iters=8, plot_particles=True, 
        xlim=(0,8), ylim=(0,8))
```

在 $x=1$ 处粒子明显多了很多，并且 $x=2$ 处也形成了像样的粒子云。显然滤波器表现更好了，但代价是大量内存使用和较长的运行时间。

另一个方法是更聪明地生成初始粒子云。假设我们猜测机器人在 (0, 0) 附近。这并不精确，因为仿真中机器人实际位于 (1, 1)，但已经接近了。如果我们在 (0, 0) 附近创建一个正态分布的粒子云，那么粒子与机器人位置匹配的概率就大得多。

`run_pf1()` 有一个可选参数 `initial_x`。可以用它来指定机器人初始位置的猜测。代码会随后调用 `create_gaussian_particles(mean, std, N)`，根据初始猜测在其周围生成正态分布的粒子。我们将在下一节使用它。

### 样本不足导致的滤波器退化（Filter Degeneracy From Inadequate Samples）

这个滤波器目前还远谈不上完美。下面是它在不同随机种子下的表现：

```python

run_pf1(N=5000, plot_particles=True, ylim=(-20, 20))
```

这里初始的粒子样本中，没有任何粒子位于机器人附近。粒子滤波器在重采样过程中并不会创建新的点，因此最终它复制的粒子并不能很好地代表概率分布。如前所述，这就是*样本贫化*。问题会迅速失控。粒子与地形测量不匹配，于是它们以高度非线性、弯曲的方式分散开来，粒子滤波器就开始偏离实际情况。机器人附近没有可用的粒子，因此它永远收敛不了。

我们使用 `create_gaussian_particles()` 方法来尝试在机器人附近生成更多点。通过使用 `initial_x` 参数指定一个位置来创建粒子。

```python

```

效果非常好。如果你有任何方式能粗略估计初始位置，应当总是尝试在该初始位置附近创建粒子。但也别*过分*小心——如果你把所有点都生成在某个单一位置非常近的地方，粒子可能因不够分散而无法捕捉系统的非线性。这是一个比较线性的系统，所以我们可以用较小的方差来创建分布。这显然取决于你的问题。增大粒子数始终是获得更好样本的一种方法，但其计算开销可能超过你愿意承受的代价。

## 重要性采样（Importance Sampling）

我前面挥挥手就略过了一个困难，现在我们必须正面处理它。存在一个用于描述机器人位置和运动的概率分布。我们想从这个分布中抽取粒子样本，并使用 MC 方法来计算积分。

困难在于：在很多问题中我们并不知道这个分布。例如，被跟踪的物体可能与我们用状态模型预测的运动方式大不相同。我们如何能从一个未知的概率分布中抽样？

统计学中有一个定理叫[*重要性采样*（importance sampling）](https://en.wikipedia.org/wiki/Importance_sampling)[1]。引人注目的是，它给我们提供了一种方法：从另一个我们*已知*的概率分布中抽样，并利用这些样本来计算未知分布的性质。这是一个让我感到欣喜的奇妙定理。

它的思想很简单，而且我们已经用过它。我们从已知的概率分布中抽样，但*根据我们感兴趣的分布对样本进行加权*。然后通过计算样本的加权均值和加权方差等量来得到所需性质。

对于机器人定位问题，我们从状态模型预测步骤计算出的概率分布中抽取粒子样本。换句话说，我们的推理是"机器人之前在那里，可能正以这个方向和速度运动，所以它现在可能在这里"。然而机器人可能干了完全不同的事情，比如掉下了悬崖，或者被迫击炮击中了。在这些情况下，概率分布并不正确。看起来似乎卡住了，但其实没有，因为我们可以使用重要性采样。我们从这个可能错误的概率分布中抽取粒子，然后根据粒子与测量的匹配程度对其加权。这一加权基于真实的概率分布，因此根据该理论，得到的均值、方差等都是正确的！

这怎么可能成立呢？我把数学推导给你看；如果你不打算超出机器人定位问题的范围，可以放心地跳过。然而其他粒子滤波问题需要不同的重要性采样思路，懂一点数学会有帮助。文献以及网上的大量内容都用数学公式表述，而不像我这种相当不严谨的"想象一下……"的叙述。如果你想读懂文献，就需要了解下面这些方程。

我们有某个概率分布 $\pi(x)$，我们希望从中抽取样本。然而，我们不知道 $\pi(x)$ 是什么；我们只知道另一个概率分布 $q(x)$。在机器人定位的语境下，$\pi(x)$ 是机器人对应的概率分布（我们不知道），而 $q(x)$ 是测量的概率分布（我们知道）。

函数 $f(x)$ 在概率分布 $\pi(x)$ 下的期望是：

$$\mathbb{E}\big[f(x)\big] = \int f(x)\pi(x)\, dx$$

我们不知道 $\pi(x)$，所以无法直接计算这个积分。但我们知道另一个分布 $q(x)$，于是可以将其乘除入积分中而不改变结果：

$$\mathbb{E}\big[f(x)\big] = \int f(x)\pi(x)\frac{q(x)}{q(x)}\, dx$$

接下来重新整理并分组：

$$\mathbb{E}\big[f(x)\big] = \int f(x)q(x)\, \,  \cdot \,  \frac{\pi(x)}{q(x)}\, dx$$

$q(x)$ 我们是已知的，所以可以用 MC 积分来计算 $\int f(x)q(x)$。这就剩下 $\pi(x)/q(x)$。它是个比值，我们把它定义为*权重*（weight）。于是得到：

$$\mathbb{E}\big[f(x)\big] = \sum\limits_{i=1}^N f(x^i)q(x^i)w(x^i)$$

也许这看起来有点抽象。如果我们想计算粒子的均值，就有：

$$\mu = \frac{1}{N}\sum\limits_{i=1}^N x^iw^i$$

这正是我前面给你的方程。

要求权重正比于比值 $\pi(x)/q(x)$。我们通常并不知道精确数值，所以在实际中通过除以 $\sum w(x^i)$ 来对权重归一化。

当你制定一个粒子滤波算法时，需要根据具体情况实现这一步。对于机器人定位问题，最适合作为 $q(x)$ 的分布是滤波器 `predict()` 步骤后的粒子分布。我们再来看代码：

```python
def update(particles, weights, z, R, landmarks):
    for i, landmark in enumerate(landmarks):
        dist = np.linalg.norm(particles[:, 0:2] - landmark, axis=1)
        weights *= scipy.stats.norm(dist, R).pdf(z[i])

    weights += 1.e-300      # 避免舍入到 0
    weights /= sum(weights) # 归一化
```

这里我们基于贝叶斯计算 $\| \text{likelihood} \times \text{prior}\|$ 来计算权重。

当然，如果你能从先验直接计算后验概率分布，那你应该这么做。如果不能，那么重要性采样为你提供了一个解决方法。在实际中，计算后验非常困难。卡尔曼滤波器之所以取得了惊人的成功，正是因为它利用了高斯分布的性质来得到解析解。一旦放宽卡尔曼滤波器所要求的条件（马尔可夫性、高斯测量与过程），重要性采样和蒙特卡洛方法便能让问题变得可解。

## 重采样方法（Resampling Methods）

重采样算法会影响滤波器的性能。例如，假设我们随机挑选粒子来重采样。这会让我们选出许多权重非常小的粒子，得到的粒子集就会变得很糟糕，无法代表问题的概率分布。

关于这个话题的研究还在继续，但已有一些算法在各种情形下都表现良好。我们希望算法具有几个性质：它应优先选择概率较高的粒子；应选择高概率粒子的代表性群体以避免样本贫化；同时应包含足够的低概率粒子以使滤波器有机会捕捉强非线性行为。

FilterPy 实现了几种流行的算法。FilterPy 并不知道你的粒子滤波器是怎么实现的，因此它无法生成新的样本。算法返回的是一个 `numpy.array`，包含被选中的粒子的索引。你的代码需要执行重采样步骤。例如我对机器人这个问题就用了：

```python
def resample_from_index(particles, weights, indexes):
    particles[:] = particles[indexes]
    weights.resize(len(particles))
    weights.fill(1.0 / len(weights))
```

### 多项式重采样（Multinomial Resampling）

多项式重采样是我开发机器人定位示例时使用的算法。其思想很简单：先计算归一化权重的累积和。这会得到一个从 0 到 1 的递增数组。下面这张图展示了如何把权重沿这种方式分隔开。颜色没有特殊含义，只是为了让分隔更明显。

```python
from kf_book.pf_internal import plot_cumsum
print('cumulative sume is', np.cumsum([.1, .2, .1, .6]))
plot_cumsum([.1, .2, .1, .6])
```

要选一个权重，我们生成一个 0 到 1 之间均匀分布的随机数，并通过二分查找在累积和数组中找到它的位置。大权重在数轴上占据更多空间，因此被选中的可能性也更大。

这用 NumPy 的 [ufunc](http://docs.scipy.org/doc/numpy/reference/ufuncs.html) 支持就能轻松实现。Ufunc 把函数作用于数组的每个元素，返回结果数组。`searchsorted` 是 NumPy 的二分查找算法。如果你给它提供一个待查值数组，它会返回一个答案数组：每个待查值对应一个答案。

```python
def multinomal_resample(weights):
    cumulative_sum = np.cumsum(weights)
    cumulative_sum[-1] = 1.  # 避免舍入误差
    return np.searchsorted(cumulative_sum, random(len(weights)))    
```

这是一个例子：

```python
from kf_book.pf_internal import plot_multinomial_resample
plot_multinomial_resample([.1, .2, .3, .4, .2, .3, .1])
```

这是一个 $O(n \log(n))$ 的算法。这并不糟糕，但还有 $O(n)$ 的重采样算法在样本均匀性方面具有更好的性质。我之所以介绍它，是因为你可以把其他算法理解为它的变体。还有一种更快的多项式重采样实现，使用分布的累积分布函数的逆函数。如果你感兴趣可以上网搜索。

### 残差重采样（Residual Resampling）

残差重采样既改善了多项式重采样的运行时间，又确保了样本在粒子集合中均匀采样。它非常巧妙：把归一化权重乘以 $N$，然后用每个权重的整数部分定义该粒子被采样的次数。例如，如果某个粒子的权重为 0.0012 且 $N = 3000$，那么放缩后的权重为 3.6，也就是该粒子会被采样 3 次。这就保证所有较高权重的粒子都至少被选中一次。运行时间是 $O(N)$，比多项式重采样更快。

但这并不会生成所有 $N$ 个样本。要选出剩下的，我们取*残差*：权重减去整数部分，剩下小数部分。然后用更简单的采样方法（例如多项式）根据残差选择剩下的粒子。在上面的例子中，放缩权重是 3.6，所以残差是 0.6 (3.6 - int(3.6))。这个残差很大，所以这个粒子很可能被再次采样。这是合理的，因为残差越大说明取整时舍入误差越大，于是该粒子在整数步骤中被相对欠采样了。

```python
def residual_resample(weights):
    N = len(weights)
    indexes = np.zeros(N, 'i')

    # 对每个权重取 int(N*w) 个副本
    num_copies = (N*np.asarray(weights)).astype(int)
    k = 0
    for i in range(N):
        for _ in range(num_copies[i]): # 复制 n 份
            indexes[k] = i
            k += 1

    # 用多项式重采样填充剩下的部分
    residual = w - num_copies     # 取小数部分
    residual /= sum(residual)     # 归一化
    cumulative_sum = np.cumsum(residual)
    cumulative_sum[-1] = 1. # 确保和精确为 1
    indexes[k:N] = np.searchsorted(cumulative_sum, random(N-k))

    return indexes
```

你可能想用切片 `indexes[k:k + num_copies[i]] = i` 来代替内层 for 循环，但很短的切片相对较慢，for 循环通常更快。


### 分层重采样（Stratified Resampling）

这种方案的目标是让选择尽可能均匀地覆盖粒子。它将累积和划分成 $N$ 个相等的区间，然后从每个区间中随机选一个粒子。这样保证任意两个相邻样本之间的距离不超过 $\frac{2}{N}$。

下图展示了这一点。彩色柱状是数组的累积和，黑色线条表示 $N$ 个相等的子区间。粒子（黑色圆点）随机散布在每个子区间中。

```python
from kf_book.pf_internal import plot_stratified_resample
plot_stratified_resample([.1, .2, .3, .4, .2, .3, .1])
```

实现分层采样的代码相当直接。

```python
def stratified_resample(weights):
    N = len(weights)
    # 划分为 N 个子区间，在每个子区间内随机选位置
    positions = (random(N) + range(N)) / N

    indexes = np.zeros(N, 'i')
    cumulative_sum = np.cumsum(weights)
    i, j = 0, 0
    while i < N:
        if positions[i] < cumulative_sum[j]:
            indexes[i] = j
            i += 1
        else:
            j += 1
    return indexes
```

### 系统重采样（Systematic Resampling）

我们要看的最后一个算法是系统重采样。与分层重采样一样，空间被划分为 $N$ 个区间。然后我们选择一个随机偏移量在所有区间中复用，确保任意两个相邻样本之间恰好相距 $\frac{1}{N}$。它看起来是这样：

```python
from kf_book.pf_internal import plot_systematic_resample
plot_systematic_resample([.1, .2, .3, .4, .2, .3, .1])
```

看过前面的例子后，这段代码再简单不过了。

```python
def systematic_resample(weights):
    N = len(weights)

    # 划分为 N 个子区间，
    # 用一个统一的随机偏移量来选择位置
    positions = (np.arange(N) + random()) / N

    indexes = np.zeros(N, 'i')
    cumulative_sum = np.cumsum(weights)
    i, j = 0, 0
    while i < N:
        if positions[i] < cumulative_sum[j]:
            indexes[i] = j
            i += 1
        else:
            j += 1
    return indexes
```

### 选择重采样算法（Choosing a Resampling Algorithm）

我们一次性看一下这四种算法，方便比较。

```python
a = [.1, .2, .3, .4, .2, .3, .1]
np.random.seed(4)
plot_multinomial_resample(a)
plot_residual_resample(a)
plot_systematic_resample(a)
plot_stratified_resample(a)
```

多项式重采样的表现相当糟糕。一个非常大的权重根本没有被采样到。最大的权重只被重采样了一次，而最小的权重却被采样了两次。我读过的网上大多数教程都使用多项式重采样，我不太明白为什么。多项式重采样在文献和实际问题中很少使用。除非你有充分的理由，否则我不推荐使用它。

残差重采样在它要做的事情上做得非常出色：确保所有最大的权重都被多次重采样。但它没有把样本均匀地分布在粒子集上——许多权重相当大的粒子根本没有被重采样。

系统和分层都表现得非常好。系统采样在确保我们从粒子空间的所有部分都进行采样的同时，能够按比例更频繁地重采样大权重粒子。分层重采样不像系统重采样那么均匀，但在确保更高权重的粒子被更多地重采样方面稍微好一些。

关于这些算法的理论性能已经写了很多，欢迎自己去阅读。在实际中，我把粒子滤波器应用于那些抗拒解析解的问题，因此我对针对这些问题进行特定分析的有效性持有些怀疑。在实践中，分层和系统两种算法在多种问题上的表现都很好且相似。我的建议是：先试一种，如果有效就用它。如果滤波器的性能很关键，那就两个都试一下，或者去看看是否有针对你具体问题的文献能给出更好的建议。

## 总结（Summary）

本章只触及了一个庞大主题的表面。我的目标不是教你掌握整个领域，而是让你接触实用的贝叶斯蒙特卡洛滤波技术。

粒子滤波器是一种*集成式*（ensemble）滤波。卡尔曼滤波器用一个高斯分布表示状态。测量通过贝叶斯定理被融合进高斯分布，预测则使用状态空间方法。这些技术都作用于高斯分布——也就是概率分布。

相比之下，集成式技术使用一组离散的点和与之关联的概率来表示概率分布。测量被作用于这些点，而不是高斯分布。同样，系统模型也作用于这些点而不是高斯分布。然后我们计算所得点集的统计性质。

这些选择带来了诸多取舍。卡尔曼滤波器非常高效，并且在线性和高斯噪声假设成立时是最优估计器。如果问题是非线性的，我们必须线性化。如果问题是多模态的（同时跟踪多个对象），卡尔曼滤波器无法表达。卡尔曼滤波器要求你知道状态模型。如果你不知道系统的行为方式，性能就会很差。

而粒子滤波器可以处理任意非解析的概率分布。只要粒子集足够大，它们就能形成对该分布的精确近似。它即使在严重非线性的情形下也表现极佳。重要性采样让我们能够在不知道底层概率分布的情况下计算概率。蒙特卡洛技术替代了其他滤波器所需的解析积分。

这种威力是有代价的。最明显的代价是滤波器对计算和内存的高消耗。不太明显的是它"挑剔"——你需要小心避免粒子退化和发散。验证滤波器的正确性可能非常困难。如果你处理的是多模态分布，你还得对粒子做聚类，以确定多个对象的轨迹。当对象彼此靠近时，这会非常困难。

粒子滤波器有许多不同的类别；我只描述了朴素的 SIS 算法，并跟着介绍了表现良好的 SIR 算法。每个类别中又有许多具体的滤波器，全部介绍它们将需要写一本小书。

当你阅读关于粒子滤波器的文献时，会发现里面到处是积分。我们用积分对概率分布进行操作，这给了作者一种强大而紧凑的表示。你必须意识到：当你把这些方程化为代码时，你将用粒子来表示分布，而积分被替换为对粒子求和。如果你记住本章的核心思想，这些材料就不会令人望而却步。
