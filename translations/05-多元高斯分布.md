## 引言

上一章的技术非常强大，但它们只能处理一个变量或一维。它们没有办法表示多维数据，例如田野中狗的位置和速度。位置和速度彼此相关，正如我们在 g-h 章节中所学到的那样，我们绝不应该丢弃信息。在本章中，我们学习如何用概率方式描述这种关系。通过这一关键洞见，我们将获得显著更好的滤波器性能。

## 多元正态分布

我们一直在为标量随机变量使用高斯分布，表示为 $\mathcal{N}(\mu, \sigma^2)$。一个更正式的术语是*单变量正态（univariate normal）*，其中 univariate 意为"一个变量"。高斯分布的概率分布称为*单变量正态分布*。

那什么是*多元正态分布（multivariate normal distribution）*？*Multivariate* 意为多个变量。我们的目标是能够表示具有多个维度的正态分布。我不一定指空间维度——如果我们跟踪飞机在 (x, y, z) 中的位置、速度和加速度，那将是一个九维问题。考虑一个二维情况。它可能是机器人的 *x* 和 *y* 坐标，可能是狗在 x 轴上的位置和速度，或者是奶牛场的牛奶产量和饲料率。这并不重要。我们可以看到，对于 $N$ 个维度，我们需要 $N$ 个均值，我们将它们排列为列矩阵（向量），如下所示：

$$
\mu = \begin{bmatrix}\mu_1\\\mu_2\\ \vdots \\\mu_n\end{bmatrix}
$$

假设我们认为 $x = 2$ 和 $y = 17$。那么我们有

$$
\mu = \begin{bmatrix}2\\17\end{bmatrix}
$$

下一步是表示我们的方差。乍一看，我们可能认为对于 N 个维度也需要 N 个方差。我们可能想说 x 的方差是 10，y 的方差是 4，如下所示：

$$\sigma^2 = \begin{bmatrix}10\\4\end{bmatrix}$$

这是不完整的，因为它没有考虑更一般的情况。在**高斯分布**章节中，我们计算了学生身高的方差。这是衡量身高彼此之间如何变化的指标。如果所有学生身高相同，那么方差为 0；如果他们的身高差异很大，那么方差就会很大。

身高和体重之间也存在关系。一般来说，较高的人比较矮的人体重更重。身高和体重是*相关的（correlated）*。我们想要一种方式不仅表达我们认为身高和体重的方差是多少，还要表达它们相关的程度。换句话说，我们想要知道体重相对于身高的变化如何。我们称之为*协方差（covariance）*。

在我们能够理解多元正态分布之前，我们需要理解相关性和协方差背后的数学。

## 相关性与协方差

*协方差（Covariance）*描述了两个变量一起变化的程度。Covariance 是 *correlated variances*（相关方差）的缩写。换句话说，*方差（variance）*是衡量总体在它们自身之间如何变化的指标，而*协方差*是衡量两个变量相对于彼此变化多少的指标。例如，随着身高增加，体重通常也会增加。这些变量是*相关的*。它们是*正相关（positively correlated）*的，因为一个变量变大时另一个也变大。随着室外温度降低，家庭取暖费用增加。这些是*反相关（inversely correlated）*或*负相关（negatively correlated）*，因为一个变量变大时另一个变量降低。茶的价格和我的狗摇尾巴的次数彼此没有关系，我们说它们是*不相关的（uncorrelated）*或*独立的（independent）*——每个都可以独立于另一个变化。

相关性允许预测。如果你比我高很多，我可以预测你也比我重。随着冬天的到来，我预测我将花更多钱来给我的房子供暖。如果我的狗摇尾巴更多，我不会得出茶价将会变化的结论。

例如，这里是学校田径队学生身高和体重的图。如果一个学生身高 68 英寸，我可以预测他们体重大约 160 磅。由于相关性不完美，我的预测也不完美。

```python
from kf_book.gaussian_internal import plot_correlated_data

height = [60, 62, 63, 65, 65.1, 68, 69, 70, 72, 74]
weight = [95, 120, 127, 119, 151, 143, 173, 171, 180, 210]
plot_correlated_data(height, weight, 'Height (in)', 'Weight (lbs)', False)
```

在本书中，我们只考虑*线性相关（linear correlation）*。我们假设变量之间的关系是线性的。也就是说，一条直线很好地拟合数据。我已经在上图中通过数据拟合了一条直线。*非线性相关（nonlinear correlation）*的概念是存在的，但我们不会使用它。

$X$ 和 $Y$ 之间协方差的方程为

$$ COV(X, Y) = \sigma_{xy} = \mathbb E\big[(X-\mu_x)(Y-\mu_y)\big]$$

其中 $\mathbb E[X]$ 是 X 的*期望值（expected value）*，定义为

$$\mathbb E[X] =  \begin{cases} \sum_{i=1}^n p_ix_i & \mbox{discrete}\\ \int_{-\infty}^\infty f(x)\, x dx & \mbox{continuous}\end{cases}$$

我们假设每个数据点的可能性相等，因此每个的概率为 $\frac{1}{N}$，给出我们将考虑的离散情况的

$$\mathbb E[X] =  \frac{1}{N}\sum_{i=1}^n x_i$$

将协方差方程与方差方程进行比较。如你所见，它们非常相似：

$$\begin{aligned}VAR(X) = \sigma_x^2 &= \mathbb E[(X - \mu)^2]\\
COV(X, Y) = \sigma_{xy} &= \mathbb E\big[(X-\mu_x)(Y-\mu_y)\big]\end{aligned}$$

特别地，如果你计算 $COV(X, X)$，你会得到 $VAR(X)$ 的方程，这支持了我的说法，即方差计算随机变量在它自身之间如何变化。

我们使用*协方差矩阵（covariance matrix）*来表示多元正态分布的协方差，它看起来像这样：

$$
\Sigma = \begin{bmatrix}
  \sigma_1^2 & \sigma_{12} & \cdots & \sigma_{1n} \\
  \sigma_{21} &\sigma_2^2 & \cdots & \sigma_{2n} \\
  \vdots  & \vdots  & \ddots & \vdots  \\
  \sigma_{n1} & \sigma_{n2} & \cdots & \sigma_n^2
 \end{bmatrix}
$$

对角线包含每个变量的方差，非对角线元素包含第 $i$ 个和第 $j$ 个变量之间的协方差。所以 $\sigma_3^2$ 是第三个变量的方差，$\sigma_{13}$ 是第一个和第三个变量之间的协方差。

协方差为 0 表示没有相关性。如果 $x$ 的方差是 10，$y$ 的方差是 4，并且 $x$ 和 $y$ 之间没有线性相关，那么我们将写为

$$\Sigma = \begin{bmatrix}10&0\\0&4\end{bmatrix}$$

如果 $x$ 和 $y$ 之间有少量正相关，我们可能有

$$\Sigma = \begin{bmatrix}10&1.2\\1.2&4\end{bmatrix}$$

其中 1.2 是 $x$ 和 $y$ 之间的协方差。我说相关性"小"是因为 1.2 的协方差相对于 10 的方差是小的。

如果 $x$ 和 $y$ 之间有大量的负相关，我们可能有

$$\Sigma = \begin{bmatrix}10&-9.7\\-9.7&4\end{bmatrix}$$

协方差矩阵是对称的。毕竟，$x$ 和 $y$ 之间的协方差总是等于 $y$ 和 $x$ 之间的协方差。也就是说，对于任何 $x$ 和 $y$，$\sigma_{xy}=\sigma_{yx}$。

我担心你可能跟丢了，所以让我们做一个例子。在**高斯分布**章节中，我们有一个学生身高 H=[1.8, 2.0, 1.7, 1.9, 1.6] 米的班级。我们计算了：

$$\begin{aligned}
\mathit{VAR}(H) &= E[(H - \mu_H)^2] \\
&= \frac{1}{N}\sum_{i=1}^n (H_i - \mu_H)^2 \\
&= \frac{1}{5}\left[(1.8-1.8)^2 + (2-1.8)^2 + (1.7-1.8)^2 + (1.9-1.8)^2 + (1.6-1.8)^2\right] \\
&= 0.02
\end{aligned}$$

简单，对吧？如果我们称量这些学生，可能会发现他们的体重为 W = [70.1, 91.2, 59.5, 93.2, 53.5]。我们能用协方差方程创建协方差矩阵吗？当然可以。它会看起来像：

$$\Sigma = \begin{bmatrix}\sigma_H^2 & \sigma_{H,W} \\
\sigma_{W,H} & \sigma_{W}^2\end{bmatrix}$$

我们刚刚计算了身高的方差，它将放在矩阵的左上角。右下角包含体重的方差。使用相同的方程我们得到：

$$\begin{aligned}
\mu_W &= \frac{1}{5}(70.1 + 91.2 + 59.5 + 93.2 + 53.5) = 73.5 \\
\sigma_W^2 &= \frac{1}{5}\left[(70.1-73.5)^2 + (91.2-73.5)^2 + (59.5-73.5)^2 + (93.2-73.5)^2 + (53.5-73.5)^2\right] \\
&= 261.8
\end{aligned}$$

现在是协方差。使用上面的公式，我们计算：

$$\begin{aligned}
\sigma_{H,W} &= \mathbb E\big[(H-\mu_H)(W-\mu_W)\big] \\
&= \frac{1}{N}\sum_{i=1}^n (H_i-\mu_H)(W_i-\mu_W) \\
&= \frac{1}{5}[(1.8-1.8)(70.1-73.5) + (2-1.8)(91.2-73.5) + (1.7-1.8)(59.5-73.5)\, +\\
&\, \, \, \,  \, (1.9-1.8)(93.2-73.5) + (1.6-1.8)(53.5-73.5)] \\
&= 2.18
\end{aligned}$$

这很繁琐，但足够简单。我们再也不会这样做了，因为当然 NumPy 会为你计算。

```python
import numpy as np

W = [70.1, 91.2, 59.5, 93.2, 53.5]
H = [1.8, 2.0, 1.7, 1.9, 1.6]
np.cov(H, W)
```

```
array([[  0.025,   2.727],
       [  2.727, 327.235]])
```

这与我们的计算不一致！出了什么问题？什么也没有。NumPy 对小样本量进行了校正；它使用 $\frac{1}{N-1}$ 作为归一化项，而不是 $\frac{1}{N}$。

这有点超出了本书的范围。简言之，假设实际班级有 200 名学生，我们抽样 5 名学生进行计算，因为我们负担不起测量和称重所有 200 名学生。几乎可以肯定我们的估计中会有一些误差，因为样本不太可能完美代表班级。随着样本大小接近 200，误差将接近 0。我们说后者没有*偏差（bias）*，并且我们有一个*无偏估计量（unbiased estimator）*。相反，当我们采取小样本时存在偏差（误差非零），我们有一个*有偏估计量（biased estimator）*。

如果误差为零，除以 $N$ 是有意义的。我不会证明为什么，但对于有偏估计量，我们使用 $\frac{1}{N-1}$ 来校正小样本量。NumPy 默认这样做，因为在实践中我们几乎总是从更大集合的数据样本中工作。如果你想要无偏估计量（即我们上面计算的），在调用 `np.cov` 时使用 `bias=1`。

```python
np.cov(H, W, bias=1)
```

```
array([[  0.02 ,   2.182],
       [  2.182, 261.788]])
```

这与我们的计算一致。在本书中我们将不再使用 `bias=1`，因为我们使用的是从我们正在跟踪的对象的无限位置集合中采样的*随机变量*。在这里，我们正在为整个总体计算方差和协方差，所以 `bias=1` 是正确的。

这个矩阵告诉我们什么？它告诉我们身高的方差是 0.02 $m^2$，体重的方差是 261.788 $kg^2$。此外，它告诉我们体重和身高是正相关的——随着身高增加，体重也增加。

让我们创建完美相关的数据。我的意思是数据完美地落在一条线上——没有偏离这条线的方差。

```python

```

```
array([[6.956, 6.956],
       [6.956, 6.956]])
```

我们可以从协方差矩阵中看到，协方差等于 x 和 y 中的方差。

现在让我们向其中一个变量添加一些噪声，使它们不再完美相关。我将让 $Y$ 为负以创建负相关。


数据不再形成一条直线。协方差是 $\sigma_{xy}=-3.08$。它与 $\sigma_x^2$ 和 $\sigma_y^2$ 的大小相比并不接近零，所以我们知道仍然有高度相关。我们可以通过查看图表来验证这一点。数据几乎形成一条直线。

现在我将向直线添加随机噪声。


## 多元正态分布方程

回想一下**高斯分布**章节中正态分布的方程：

$$
f(x, \mu, \sigma) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp \Big [{-\frac{1}{2}}{(x-\mu)^2}/\sigma^2 \Big ]
$$

这是 $n$ 维多元正态分布。

$$
f(\mathbf{x},\, \mu,\,\Sigma) = \frac{1}{\sqrt{(2\pi)^n|\Sigma|}}\, \exp  \Big [{ -\frac{1}{2}(\mathbf{x}-\mu)^\mathsf{T}\Sigma^{-1}(\mathbf{x}-\mu) \Big ]}
$$

多元版本只是用矩阵替换了单变量方程中的标量。如果你对线性代数有一定了解，这个方程应该看起来相当易于处理。如果不是，别担心，FilterPy 和 SciPy 都提供了为你计算它的函数。让我们暂时忽略计算并将其绘制出来，看看它是什么样子。

```python
import kf_book.mkf_internal as mkf_internal

mean = [2., 17.]
cov = [[10., 0.], 
       [0., 4.]]

mkf_internal.plot_3d_covariance(mean, cov)
```

这是均值为 $\mu=[\begin{smallmatrix}2\\17\end{smallmatrix}]$、协方差为 $\Sigma=[\begin{smallmatrix}10&0\\0&4\end{smallmatrix}]$ 的多元高斯分布的图。三维形状显示了 z 轴上 $(X, Y)$ 任意值的概率密度。我已将 x 和 y 的方差投影到图表的墙上——你可以看到它们呈现出高斯钟形曲线的形状。$X$ 的曲线比 $Y$ 的曲线更宽，这由 $\sigma_x^2=10$ 和 $\sigma_y^2=4$ 解释。3D 表面的最高点位于 $X$ 和 $Y$ 的均值处。

所有的多元高斯分布都具有这种形状。如果我们将其视为狗位置的高斯分布，那么 $(X, Y)$ 每一点的 z 值就是狗在该位置的概率密度。严格来说，这是*联合概率密度函数（joint probability density function）*，我很快就会定义。所以，狗在 (2, 17) 附近的概率最高，在 (5, 14) 附近的概率适中，在 (10, 10) 附近的概率非常低。与单变量情况一样，这是*概率密度（probability density）*，而不是*概率（probability）*。连续分布有无限的范围，因此恰好在 (2, 17) 或任何其他点的概率为 0%。我们可以通过用积分计算表面下的体积来计算在给定范围内的概率。

FilterPy [2] 在 `filterpy.stats.` 模块中通过函数 `multivariate_gaussian()` 实现该方程。SciPy 的 `stats` 模块通过 `multivariate_normal()` 实现多元正态方程。它实现了一种"冻结"形式，你只需设置一次均值和协方差，然后可以在任意多次调用中为任意数量的 x 值计算概率密度。我将我的函数命名为 `multivariate_gaussian()`，以确保它永远不会与 SciPy 版本混淆。

> `scipy.stats` 模块的[教程](http://docs.scipy.org/doc/scipy/reference/tutorial/stats.html)[1]解释了"冻结"分布和其他非常有用的特性。

是时候定义一些术语了。*联合概率（joint probability）*，记为 $P(x,y)$，是 $x$ 和 $y$ 同时发生的概率。例如，如果你掷两个骰子，$P(2,5)$ 是第一个骰子掷出 2 和第二个骰子掷出 5 的概率。假设骰子是六面公平的，概率 $P(2,5) = \frac{1}{6}\times \frac{1}{6}=\frac{1}{36}$。上面的 3D 图显示了*联合概率密度函数*。

*边缘概率（marginal probability）*是某事件在不考虑任何其他事件的情况下发生的概率。在上面的图表中，绘制在左侧的高斯曲线是 $Y$ 的边缘概率。这是不考虑 $X$ 值时狗在 $Y$ 任意位置的概率。早些时候我写道"我已将 x 和 y 的方差投影到图表的墙上"；这些是 $x$ 和 $y$ 的边缘概率。高斯分布的另一个计算优势是多元高斯分布的边缘是另一个高斯分布！

让我们以略微不同的方式来看。我不绘制显示概率分布的表面，而是生成具有 $[\begin{smallmatrix}8&0\\0&3\end{smallmatrix}]$ 分布的 1,000 个点。

这些图看起来像圆和椭圆。事实上，多元高斯分布的任何切片都是椭圆。因此，在统计学中，我们不称这些为"等高线图"，而称为*误差椭圆（error ellipses）*或*置信椭圆（confidence ellipses）*；这些术语可以互换。

这段代码使用了 `filterpy.stats` 中的 `plot_covariance_ellipse()` 函数。默认情况下，该函数显示一个标准差，但你可以使用 `variance` 或 `std` 参数来控制显示的内容。例如，`variance=3**2` 或 `std=3` 将显示第 3 个标准差，而 `variance=[1,4,9]` 或 `std=[1,2,3]` 将显示第 1、第 2 和第 3 个标准差。

```python
from filterpy.stats import plot_covariance_ellipse
import matplotlib.pyplot as plt

P = [[2, 0], [0, 6]]
plot_covariance_ellipse((2, 7), P, fc='g', alpha=0.2, 
                        std=[1, 2, 3],
                        title='|2 0|\n|0 6|')
plt.gca().grid(b=False);
```

实心颜色可能向你暗示在标准差之间的概率分布是恒定的。这不是真的，正如你可以从高斯的 3D 图中看出的那样。这是协方差 $\begin{smallmatrix}2&1.2\\1.2&1.3\end{smallmatrix}$ 的概率分布的 2D 阴影表示。深灰色对应于较高的概率密度。

```python
from kf_book.nonlinear_plots import plot_cov_ellipse_colormap
plot_cov_ellipse_colormap(cov=[[2, 1.2], [1.2, 1.3]]);
```

思考这些图的物理解释可以阐明它们的含义。第一个图的均值和协方差是

$$
\mathbf{\mu} =\begin{bmatrix}2\\7\end{bmatrix},\, \,
\Sigma = \begin{bmatrix}2&0\\0&2 \end{bmatrix}
$$

```python
x = [2, 7]
P = [[2, 0], [0, 2]]
plot_covariance_ellipse(x, P, fc='g', alpha=0.2, 
                       title='|2 0|\n|0 2|')
plt.gca().grid(b=False)
```

贝叶斯思考方式是椭圆向我们展示了我们信念中的误差量。一个微小的圆表示我们的误差非常小，而一个非常大的圆表示我们信念中存在大量误差。椭圆的形状向我们展示了 $X$ 和 $Y$ 中误差的几何关系。这里我们有一个圆，所以 $X$ 和 $Y$ 中的误差同样可能。

第二个图的均值和协方差是

$$
\mu =\begin{bmatrix}2\\7\end{bmatrix}, \, \, \, 
\Sigma = \begin{bmatrix}2&0\\0&6\end{bmatrix}
$$

```python
x = [2, 7]

                    title='|2 0|\n|0 6|')
plt.gca().grid(b=False)
```

这次我们对 $X$（$\sigma_x^2=2$）与 $Y$（$\sigma^2_y=6$）使用了不同的方差。结果是一个高而窄的椭圆。我们可以看到 $Y$ 中的不确定性比 $X$ 中的多得多。在这两种情况下，我们都认为狗在 (2, 7)，但不确定性是不同的。

第三个图显示均值和协方差

$$
\mu =\begin{bmatrix}2\\7\end{bmatrix}, \, \, \, 
\Sigma = \begin{bmatrix}2&1.2\\1.2&2\end{bmatrix}
$$

```python
x = [2, 7]
P = [[2, 1.2], [1.2, 2]]
plot_covariance_ellipse(x, P, fc='g', alpha=0.2, 
                    title='|2 1.2|\n|1.2 2|')
```

这是协方差矩阵非对角元素中具有值的第一个等高线，也是第一个具有倾斜椭圆的等高线图。这不是巧合。这两个事实告诉我们同样的事情。倾斜的椭圆告诉我们 $x$ 和 $y$ 值在某种程度上是相关的。协方差矩阵中的非对角元素非零，表明存在相关性。

### 皮尔逊相关系数

我们在本书中不会使用这个系数，但你可能在其他地方看到它。如果不感兴趣，可以安全地跳过本节。

两个变量之间的相关性可以通过*皮尔逊相关系数（Pearson's Correlation Coefficient）*获得一个数值。它定义为

$$\rho_{xy} = \frac{COV(X, Y)}{\sigma_x \sigma_y}$$

这个值的范围可以从 -1 到 1。如果协方差为 0，则 $\rho=0$。大于 0 的值表示关系是正相关，负值表示存在负相关。接近 -1 或 1 的值表示非常强的相关性，接近 0 的值表示非常弱的相关性。

相关性和协方差密切相关。协方差有与之关联的单位，而相关性是无单位的比率。例如，对于我们的狗，$\sigma_{xy}$ 的单位是平方米。

我们可以使用 `scipy.stats.pearsonr` 函数来计算皮尔逊系数。它返回皮尔逊系数和双尾 p 值的元组。后者在本书中不使用。这里我们计算学生运动员身高与体重的 $\rho$：

```python
from scipy.stats import pearsonr
pearsonr(height, weight)[0]
```

```
0.9539731096080194
```

这里我们计算发动机温度和寿命之间的相关性。

```python
pearsonr(max_temp, lifespan)[0]
```

```
-0.9178223453527254
```

关于*相关性（correlation）*和*独立性（independence）*的一个说明。如果变量是*独立（independent）*的，它们可以分开变化。如果你在开阔的田野中行走，你可以在 $x$ 方向（东-西）、$y$ 方向（南-北）或它们的任意组合中移动。独立变量也总是*不相关（uncorrelated）*的。除特殊情况外，反之不成立。变量可以不相关但相依。例如，考虑 $y=x^2$。相关性是线性度量，所以 $x$ 和 $y$ 不相关。然而，$y$ 依赖于 $x$。

## 乘以多维高斯分布

在上一章中，我们通过将不确定的测量值与不确定的估计值的高斯分布相乘来合并它们。结果是另一个具有较小方差的高斯分布。如果两条不确定信息相互证实，我们应该对结论更有信心。图形看起来像这样：

```python
mkf_internal.plot_gaussian_multiply()
```

测量值 1 和 2 的组合产生更大的确定性，所以新的高斯分布更高更窄——方差变小了。同样的事情发生在多维多元高斯分布上。

这是乘以多元高斯分布的方程。大写的 sigma（$\Sigma$）表示这些是矩阵，而不是标量。具体来说，它们是协方差矩阵：

$$\begin{aligned}
\mu &= \Sigma_2(\Sigma_1 + \Sigma_2)^{-1}\mu_1 + \Sigma_1(\Sigma_1 + \Sigma_2)^{-1}\mu_2 \\
\Sigma &= \Sigma_1(\Sigma_1+\Sigma_2)^{-1}\Sigma_2
\end{aligned}$$

它们是通过将先验和估计的多元高斯分布代入贝叶斯定理生成的。我在**高斯分布**章节给出了单变量情况的代数。

你不需要记住这些方程，因为它们由很快就会呈现的卡尔曼滤波器方程计算。这种计算也可以在 FilterPy 中使用 `multivariate_multiply()` 方法，你可以从 `filterpy.stats` 导入。

为了给你一些直觉，回想一下乘以单变量高斯分布的方程：

$$\begin{aligned}
\mu &=\frac{\sigma_1^2 \mu_2 + \sigma_2^2 \mu_1} {\sigma_1^2 + \sigma_2^2}, \\
\sigma^2 &= \frac{\sigma_1^2\sigma_2^2}{\sigma_1^2+\sigma_2^2}
\end{aligned}$$

这看起来类似于多元方程。如果你认识到由 -1 次方表示的矩阵求逆*类似于*倒数（因为 $AA^{-1} =I$），这将更加明显。我将求逆改写为除法——这在数学上是不正确的事情，因为对矩阵的除法是未定义的，但它确实有助于我们比较方程。

$$\begin{aligned}
\mu &\approx \frac{\Sigma_2\mu_1 + \Sigma_1\mu_2}{\Sigma_1 + \Sigma_2} \\ \\
\Sigma &\approx \frac{\Sigma_1\Sigma_2}{(\Sigma_1+\Sigma_2)}
\end{aligned}$$

在这种形式下，单变量和多元方程之间的关系是清楚的。

现在让我们以一个具体的例子来探索多元高斯分布。假设我们正在用两个雷达系统跟踪飞机。我将忽略高度，以便我可以使用二维图。雷达提供到目标的距离和方位。我们一开始对飞机的位置不确定，因此协方差（即我们对位置的不确定性）可能看起来像这样。在贝叶斯统计的语言中，这是我们的*先验*。

```python
P0 = [[6, 0], [0, 6]]
plot_covariance_ellipse((10, 10), P0, fc='y', alpha=0.6)
```

现在假设飞机的左下方有一个雷达。进一步假设雷达的方位测量是准确的，但距离测量是不准确的。测量误差的协方差可能看起来像这样（绘制为黄色先验之上的绿色）：

```python
P1 = [[2, 1.9], [1.9, 2]]
plot_covariance_ellipse((10, 10), P0, fc='y', alpha=0.6)
plot_covariance_ellipse((10, 10), P1, fc='g', alpha=0.9)
```

回想一下，贝叶斯统计称之为*证据（evidence）*。椭圆指向雷达。它非常长，因为距离测量不准确，飞机可能在测量距离的相当远的范围内。它非常窄，因为方位估计非常准确，因此飞机必须非常接近方位估计。

我们想要找到*后验*——即将证据合并到先验中的均值和协方差。与所有其他章节一样，我们通过将证据相乘来合并证据。

```python
from filterpy.stats import multivariate_multiply

P2 = multivariate_multiply((10, 10), P0, (10, 10), P1)[1]
plot_covariance_ellipse((10, 10), P0, ec='k', fc='y', alpha=0.2)
plot_covariance_ellipse((10, 10), P1, ec='k', fc='g', alpha=0.9)
plot_covariance_ellipse((10, 10), P2, ec='k', fc='b')
```

我用非常透明的黄色绘制了原始估计（先验），用绿色绘制了雷达读数（证据），用蓝色绘制了最终估计（后验）。

后验保留了与雷达测量相同的形状和位置，但更小。我们已经在一维高斯分布中看到了这一点。两个高斯分布相乘会使方差变小，因为我们正在合并更多信息，因此我们的不确定性更小。另一个要认识的点是协方差形状反映了飞机和雷达系统的物理布局。这一点的重要性将在下一步中变得清晰。

现在让我们说我们从第二个雷达获得测量值，这次是右下方。来自最后一步的后验成为我们新的先验，我用黄色绘制。新的测量值用绿色绘制。

```python
P3 = [[2, -1.9], [-1.9, 2.2]]
plot_covariance_ellipse((10, 10), P2, ec='k', fc='y', alpha=0.6)
plot_covariance_ellipse((10, 10), P3, ec='k', fc='g', alpha=0.6)
```

我们通过乘以高斯分布来合并这些信息：

```python
P4 = multivariate_multiply((10, 10), P2, (10, 10), P3)[1]
plot_covariance_ellipse((10, 10), P2, ec='k', fc='y', alpha=0.6)
plot_covariance_ellipse((10, 10), P3, ec='k', fc='g', alpha=0.6)
plot_covariance_ellipse((10, 10), P4, ec='k', fc='b')
```

飞机唯一可能的位置是两个椭圆相交的地方。通过将先验和测量值相乘形成的相交是一个新的高斯分布。形状反映了问题的几何结构。这使我们能够*三角测量（triangulate）*飞机，从而获得非常准确的估计。我们没有显式编写任何代码来执行三角测量；这是将每个测量值的高斯分布相乘的自然结果。

回想一下 **g-h 滤波器** 章节，我们显示了秤上两次称重的误差棒。估计必须落在误差棒重叠的区域内。这里估计必须落在 161 到 163 磅之间。

```python
import kf_book.book_plots as book_plots
book_plots.plot_errorbars([(160, 8, 'A'), (170, 8, 'B')], xlims=(150, 180))
```

让我们考虑一个不同的布局。假设第一个雷达直接位于飞机的左侧。我可以用以下方式建模测量误差
$$\Sigma = \begin{bmatrix}2&0\\0&0.2\end{bmatrix}$$

这里我们看到先验与测量值相乘的结果。

```python
P1 = [[2, 0], [0, .2]]
P2 = multivariate_multiply((10, 10), P0, (10, 10), P1)[1]
plot_covariance_ellipse((10, 10), P0, ec='k', fc='y', alpha=0.2)

plot_covariance_ellipse((10, 10), P2, ec='k', fc='b')
```

现在我们可以合并第二个雷达系统的测量值，我们将其保持在与之前相同的位置。

```python
P3 = [[2, -1.9], [-1.9, 2.2]]
P4 = multivariate_multiply((10, 10), P2, (10, 10), P3)[1]
plot_covariance_ellipse((10, 10), P2, ec='k', fc='y', alpha=0.2)
plot_covariance_ellipse((10, 10), P3, ec='k', fc='g', alpha=0.6)
```

作为最后一个例子，想象在短时间间隔内从同一个雷达进行两次测量。协方差椭圆将几乎重叠，在我们的新估计中留下非常大的误差：

## 隐藏变量

你已经可以看出为什么多元卡尔曼滤波器可以比单变量卡尔曼滤波器表现得更好。变量之间的相关性可以显著改进我们的估计。我们可以将其推得更远。**本节包含本章的关键洞见，请仔细阅读**。

假设我们正在跟踪一架飞机，并在 $t$=1、2 和 3 秒时获得 $x$ 和 $y$ 坐标的以下数据。你的直觉告诉你 $x$ 在 $t$=4 秒时的值是多少？

```python
mkf_internal.show_position_chart()
```

似乎飞机正在直线飞行，而我们知道飞机不能瞬间转弯。最合理的猜测是在 $t$=4 时飞机位于 (4,4)。我将用一个绿色箭头描绘它。

```python
mkf_internal.show_position_prediction_chart()
```

你做出这一推断是因为你*推测（inferred）*了飞机的恒定速度。合理的假设是飞机每个时间步在 *x* 和 *y* 方向上各移动一个单位。

回想一下 **g-h 滤波器**章节中我们尝试改进带噪声秤的体重预测。我们将*体重增长*纳入方程，因为它使我们能够更好地预测第二天的体重。g-h 滤波器使用 $g$ 参数缩放对当前体重测量值的重视程度，而 $h$ 参数缩放对体重增长的重视程度。

我们将对卡尔曼滤波器做同样的事情。毕竟，卡尔曼滤波器是 g-h 滤波器的一种形式。在这种情况下，我们正在跟踪一架飞机，因此我们需要跟踪位置和速度，而不是体重和体重增长。体重增长是体重的*导数（derivative）*，而速度当然是位置的导数。绘制和理解需要绘制 *x* 和 *y* 及其各自速度的 4D 图表是不可能的，所以让我们对 $x$ 这样做，知道数学可以推广到更多维度。

在时刻 1，我们可能对位置（x=0）相当确定，但对速度一无所知。我们可以用这样的协方差矩阵绘制它。较窄的宽度表达了我们对位置的相对确定性，而较高的高度表达了我们对速度知识的缺乏。

```python
mkf_internal.show_x_error_chart(1)
```

然而，位置和速度是相关的。如果速度为 5 m/s，那么 1 秒后位置将为 5 m。如果速度为 -10 m/s，那么 1 秒后位置将为 -10 m。让我们用绘制在对角线上的速度协方差来可视化这一点。

```python
mkf_internal.show_x_error_chart(2)
```

此时速度协方差对我们没有帮助。我们无法预测新位置，因为我们对速度一无所知。但 1 秒后我们获得位置更新 x=5。

```python
mkf_internal.show_x_error_chart(3)
```

直到下一章才会清楚我如何计算我即将所说的内容。忽略计算，思考这意味着什么。我们没有简单的方法说出对象真正在哪里，因为我们对速度非常不确定。因此椭圆在 x 轴上拉伸得很远。我们对速度的不确定性当然意味着它在 y 轴上也非常分散。但正如我在上一段中所说的，位置与速度相关。如果速度是 5 m/s，下一个位置将是 5；如果速度是 10，下一个位置将是 10。它们高度相关，所以椭圆必须非常窄。

这两个协方差的叠加是奇迹发生的地方。在 t=1（位置=5 处）的唯一合理估计大致是速度协方差与测量协方差的交集！更准确地说，我们可以使用上一节的数学并将两个协方差相乘。从贝叶斯的角度看，我们将先验与证据的概率（*似然*）相乘以获得后验。如果我们使用贝叶斯方程将位置协方差与速度协方差相乘，我们得到这个结果：

```python
mkf_internal.show_x_error_chart(4)
```

新的协方差（后验）位于位置协方差和速度协方差的交集处。它略微倾斜，表明位置和速度之间存在某种相关性。更重要的是，它比位置或速度协方差都小得多。在上一章中，每次执行 `update()` 时方差会变小，因为先前的估计与新测量值相乘。同样的事情在这里发生。然而，这里的改进明显更好。这是因为我们使用了两条不同但相关的信息。大致知道速度及其相关性以及大致知道位置使我们能够做出非常准确的估计。从这个图中不容易看出，但位置的不确定性变小了。我们知道这一点是因为新协方差在 x 轴上没有像 t=1 处的测量协方差延伸那么远。所以我们不仅对速度更确定，而且我们对位置也比仅使用位置测量而不考虑速度时更确定！

这是一个关键点，请仔细阅读！雷达只检测飞机的位置。这被称为*观测变量（observed variable）*。基于位置估计，我们可以计算速度。我们将速度称为*隐藏变量（hidden variable）*。隐藏的意思就如其听起来的——没有传感器在测量速度，因此其值对我们来说是隐藏的。我们能够利用位置和速度之间的相关性非常准确地推断其值。

为了完整说明术语，还有*不可观测变量（unobserved variables）*。例如，飞机的状态包括航向、发动机 RPM、重量、颜色、飞行员的名字等等。我们不能使用位置传感器直接感知它们，因此它们不是*被观测的*。没有方法从传感器测量值和相关性推断它们（红色飞机不会比白色飞机飞得更快），所以它们不是*隐藏的*。相反，它们是*不可观测的*。如果你在滤波器状态中包含一个不可观测变量，该变量的估计将是无意义的。

是什么使这成为可能？想象一下，我们将另一架飞机的速度叠加在位置图上。显然，这两者是不相关的，没有任何方式将这两者结合起来可能产生任何额外信息。相比之下，这架飞机的速度告诉我们一些非常重要的事情——飞行的方向和速度。只要飞机不改变其速度，速度就允许我们预测下一个位置在哪里。在速度出现相对较小的误差后，它与位置匹配良好的概率很小。想想看——如果你突然改变方向，你的位置也会发生很大变化。如果位置的测量值不在速度变化的方向上，则不太可能为真。两者是相关的，所以如果速度变化，位置也必须变化，并且以一种可预测的方式。

理解我们正在利用速度和位置相关这一事实非常重要。我们从两次测量之间的距离和时间得到速度的粗略估计，并使用贝叶斯定理在仅几次观察后产生非常准确的估计。如果你有任何疑问，请重读本节。如果你不理解这一点，你将很快发现无法对你将在后续章节中学习的内容进行推理。

如果你只关心位置，包含速度的影响在我看来微不足道。但这只是在一次更新之后。在下一章中，我们将看到经过多次更新后我们的确定性会有怎样巨大的增加。测量方差会很大，但估计的位置方差会很小。每次将速度协方差与位置相交时，它在 x 轴上变得更窄，因此每次方差也变得更小。

## 更高维度

到目前为止，我已经向你展示了二维高斯分布，但数学并没有将你限制在二维。在后续章节中，我们将在 9 维甚至 12 维中工作。如果你在天气预测等领域工作，你最终可能会有数千个维度。

这些更高维度"看起来"像什么？嗯，二维高斯分布可以由误差椭圆表示，因此可以推断三维高斯分布可以由 3D 误差椭球体表示。我们不会在这里深入数学，但这确实成立。`FilterPy` 提供了绘制此椭球体的函数。

首先，让我们用给定的协方差创建一些带噪声的数据，以便我们可以将其绘制在椭球体内部。

```python
from filterpy.stats import plot_3d_covariance

mu = [0.3, 5., 10.]
C = np.array([[1.0, .03, .2],
              [.03,  4.0, .0],
              [.2,  .0, 16.1]])

sample = np.random.multivariate_normal(mu, C, size=1000)
```

现在我们使用 `FilterPy` 函数 `plot_3d_covariance` 绘制椭球体，然后散点绘制样本。

```python
ax = plot_3d_covariance(mu, C, alpha=.4, std=3, limit_xyz=True)
ax.scatter(sample[:, 0], sample[:, 1], zs=sample[:, 2],);
```

理论指出大约 99% 的分布将落在 3 个标准差内，看起来确实如此。

九维呢？我还没有完全弄清楚如何在 2D 屏幕上绘制 9D 椭球体，因此没有图。概念是一样的；分布的标准差误差可以用 9D 椭球体描述。

## 总结

我们利用系统的几何形状和相关性产生了非常准确的估计。数学并不关心我们是在处理两个位置，还是一个位置和一个相关的速度，或者这些是空间维度。如果地板面积与房价相关，你可以编写一个卡尔曼滤波器来跟踪房价。如果年龄与疾病发病率相关，你可以编写一个卡尔曼滤波器来跟踪疾病。如果僵尸种群与霰弹枪数量呈反比，那么你可以编写一个卡尔曼滤波器来跟踪僵尸种群。我用几何术语向你展示了这一点，并谈到了*三角测量*。那只是为了建立你的直觉。你可以为没有几何表示的状态变量编写卡尔曼滤波器，例如用于股票价格或奶牛产奶量的滤波器（我收到过一封跟踪产奶量的人的电子邮件！）习惯于将这些视为具有相关性的高斯分布。如果我们能将不确定性表达为多维高斯分布，那么我们就可以将先验与似然相乘，并获得更准确的结果。
