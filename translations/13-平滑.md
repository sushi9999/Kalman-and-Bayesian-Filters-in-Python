## 平滑器工作原理概述

卡尔曼滤波器是一个具有马尔可夫性质的*递归*滤波器——它在步骤 `k` 的估计只基于步骤 `k-1` 的估计和步骤 `k` 的测量值。但这意味着步骤 `k-1` 的估计基于步骤 `k-2`，依此类推，一直追溯到第一个时刻。因此，步骤 `k` 的估计依赖于所有之前的测量值，尽管影响程度不同。`k-1` 的影响最大，`k-2` 次之，以此类推。

平滑滤波器将未来的测量值融合到步骤 `k` 的估计中。来自 `k+1` 的测量值影响最大，`k+2` 影响较小，`k+3` 更小，以此类推。

这个主题被称为*平滑*（smoothing），但我认为这个名字有误导性。我可以通过低通滤波器来平滑上面的数据。结果会很平滑，但不一定准确，因为低通滤波器在去除噪声的同时也会去除真实的变化。相比之下，卡尔曼平滑器是*最优的*——它们融合所有可用信息来做出数学上可实现的最佳估计。

## 平滑器的类型

有三类卡尔曼平滑器可以在这些情况下提供更好的跟踪。

* 固定区间平滑（Fixed-Interval Smoothing）

这是一种基于批处理的滤波器。该滤波器等待收集所有数据后才进行估计。例如，你可能是一位正在收集实验数据的科学家，在实验完成之前不需要知道结果。固定区间平滑器会收集所有数据，然后使用所有可用的过去和未来测量值来估计每个测量点的状态。如果可以在批处理模式下运行卡尔曼滤波器，始终建议使用这些滤波器之一，因为它会比前几章的递归形式滤波器提供更好的结果。

* 固定延迟平滑（Fixed-Lag Smoothing）

固定延迟平滑器在输出中引入延迟。假设我们选择 4 步的延迟。滤波器会摄入前 3 个测量值，但不会输出滤波结果。然后，当第 4 个测量值到来时，滤波器会产生测量值 1 的输出，考虑测量值 1 到 4。当第 5 个测量值到来时，滤波器会产生测量值 2 的结果，考虑测量值 2 到 5。当你需要最近的数据但可以承受一点延迟时，这很有用。例如，你可能使用机器视觉来监控制造过程。如果你能承受几秒钟的估计延迟，固定延迟平滑器可以让你产生非常准确和平滑的结果。

* 固定点平滑（Fixed-Point Smoothing）

固定点滤波器像普通卡尔曼滤波器一样运行，但也对某个固定时间 $j$ 的状态进行估计。在时间 $k$ 到达 $j$ 之前，滤波器像普通滤波器一样运行。一旦 $k>j$，滤波器估计 $x_k$，然后使用 $j\dots k$ 之间的所有测量值更新对 $x_j$ 的估计。这可用于估计系统的初始参数，或为发生在特定时间的事件产生最佳估计。例如，你可能有一个机器人在时间 $j$ 拍摄了一张照片。随着机器人继续移动，你可以使用固定点平滑器获得时间 $j$ 相机的最佳姿态信息。

## 滤波器的选择

这些滤波器的选择取决于你的需求以及你能够提供多少内存和处理时间。固定点平滑需要存储所有测量值，而且计算成本很高，因为每个时间步的输出都要针对每个测量值重新计算。另一方面，该滤波器确实为当前测量产生了不错的输出，因此该滤波器可用于实时应用。

固定延迟平滑只需要存储一个数据窗口，处理需求适中，因为每次新测量只处理该窗口。缺点是滤波器的输出总是滞后于输入，而且平滑效果不如固定区间平滑那么明显。

固定区间平滑以批处理为代价产生最平滑的输出。大多数算法使用某种前向/后向算法，速度仅比递归卡尔曼滤波器慢两倍。

## 固定区间平滑

文献中有许多固定延迟平滑器可用。我选择实现由 Rauch、Tung 和 Striebel 发明的平滑器，因为它易于实现且计算效率高。它也是我在实际应用中最常看到的平滑器。这种平滑器通常被称为 RTS 平滑器。

RTS 平滑器的推导需要几页密集的数学。我不打算让你受这个罪。相反，我将简要介绍算法和方程，然后直接进入平滑器的实现和演示。

RTS 平滑器的工作原理是首先以批处理模式运行卡尔曼滤波器，计算每一步的滤波器输出。给定每个测量的滤波器输出以及与每个输出对应的协方差矩阵，RTS 向后遍历数据，将其对未来的了解融合到过去的测量中。当它到达第一个测量值时就完成了，滤波输出以最优形式融合了所有信息。

RTS 平滑器的方程非常直接且易于实现。这个推导是针对线性卡尔曼滤波器的。EKF 和 UKF 也存在类似的推导。这些步骤在批处理的输出上执行，从最近的时间向后到第一个估计。每次迭代都将对未来的了解融合到状态估计中。由于状态估计已经融合了所有过去的测量值，结果将是每个估计都包含所有过去和未来测量值的知识。在这里区分过去、现在和未来非常重要，所以我使用下标来表示数据是否来自未来。

预测步骤

$$\begin{aligned}
\mathbf{P} &= \mathbf{FP}_k\mathbf{F}^\mathsf{T} + \mathbf{Q }
\end{aligned}$$

更新步骤

$$\begin{aligned}
\mathbf{K}_k &= \mathbf{P}_k\mathbf{F}^\mathsf{T}\mathbf{P}^{-1} \\
\mathbf{x}_k &= \mathbf{x}_k + \mathbf{K}_k(\mathbf{x}_{k+1} - \mathbf{Fx}_k) \\
\mathbf{P}_k &= \mathbf{P}_k + \mathbf{K}_k(\mathbf{P}_{k+1} - \mathbf{P})\mathbf{K}_k^\mathsf{T}
\end{aligned}$$

一如既往，实现中最困难的部分是正确处理下标。一个没有注释或错误检查的基本实现如下：

```python
def rts_smoother(Xs, Ps, F, Q):
    n, dim_x, _ = Xs.shape

    # smoother gain
    K = zeros((n,dim_x, dim_x))
    x, P, Pp = Xs.copy(), Ps.copy(), Ps.copy

    for k in range(n-2,-1,-1):
        Pp[k] = F @ P[k] @ F.T + Q # predicted covariance

        K[k]  = P[k] @ F.T @ inv(Pp[k])
        x[k] += K[k] @ (x[k+1] - (F @ x[k]))     
        P[k] += K[k] @ (P[k+1] - Pp[k]) @ K[k].T
    return (x, P, K, Pp)
```

这个实现与 FilterPy 中提供的实现相同。它假设卡尔曼滤波器在外部以批处理模式运行，状态和协方差的结果通过 `Xs` 和 `Ps` 变量传入。

然而，我们必须明白，这种平滑是基于系统模型的。我们已经告诉滤波器，我们跟踪的对象遵循一个过程误差非常低的恒速模型。当滤波器*向前看*时，它看到未来的行为与恒速非常匹配，因此能够拒绝信号中的大部分噪声。假设我们的系统有很大的过程噪声。例如，如果我们在阵风中跟踪一架轻型飞机，其速度会经常变化，滤波器将更难以区分噪声和由于风造成的不规则运动。我们可以在下一张图中看到这一点。

这强调了一个事实：这些滤波器并不是在通俗意义上*平滑*数据。滤波器是基于过去的测量值、未来的测量值以及你告诉它的关于系统行为和系统及测量中噪声的信息来进行最优估计的。

## 固定延迟平滑

上面介绍的 RTS 平滑器应该始终是你的算法选择，如果你可以在批处理模式下运行的话，因为它将所有可用数据融合到每个估计中。并非所有问题都允许你这样做，但你可能仍然希望接收之前估计的平滑值。下面的数轴说明了这个概念。

在步骤 $k$，我们可以使用正常的卡尔曼滤波器方程估计 $x_k$。然而，我们可以使用 $x_k$ 收到的测量值对 $x_{k-1}$ 做出更好的估计。同样，我们可以使用 $x_{k-1}$ 和 $x_{k}$ 收到的测量值对 $x_{k-2}$ 做出更好的估计。我们可以将这个计算向后延伸任意 $N$ 步。

这个数学的推导超出了本书的范围；Dan Simon 的《最优状态估计》[2] 如果你感兴趣的话有一个非常好的阐述。这个想法的本质是，我们不是有一个状态向量 $\mathbf{x}$，而是做一个包含以下内容的增广状态：

$$\mathbf{x} = \begin{bmatrix}\mathbf{x}_k \\ \mathbf{x}_{k-1} \\ \vdots\\ \mathbf{x}_{k-N+1}\end{bmatrix}$$

这产生一个非常大的协方差矩阵，包含不同步骤状态之间的协方差。FilterPy 的 `FixedLagSmoother` 类为你处理所有这些计算，包括创建增广矩阵。你需要做的就是像使用 `KalmanFilter` 类一样组合它，然后调用 `smooth()`，它实现了算法的预测和更新步骤。

每次调用 `smooth` 都会计算当前测量的估计，但它也会回溯并调整之前的 `N-1` 个点。平滑值包含在列表 `FixedLagSmoother.xSmooth` 中。如果你使用 `FixedLagSmoother.x`，你将得到最新的估计，但它没有被平滑，与标准卡尔曼滤波器输出没有区别。

```python
from filterpy.kalman import FixedLagSmoother, KalmanFilter
import numpy.random as random

fls = FixedLagSmoother(dim_x=2, dim_z=1, N=8)

fls.x = np.array([0., .5])
fls.F = np.array([[1.,1.],
                  [0.,1.]])

fls.H = np.array([[1.,0.]])
fls.P *= 200
fls.R *= 5.
fls.Q *= 0.001

kf = KalmanFilter(dim_x=2, dim_z=1)
kf.x = np.array([0., .5])
kf.F = np.array([[1.,1.],
                 [0.,1.]])
kf.H = np.array([[1.,0.]])
kf.P *= 200
kf.R *= 5.
kf.Q = Q_discrete_white_noise(dim=2, dt=1., var=0.001)

N = 4 # size of lag

nom =  np.array([t/2. for t in range (0, 40)])
zs = np.array([t + random.randn()*5.1 for t in nom])

for z in zs:
    fls.smooth(z)
    
kf_x, _, _, _ = kf.batch_filter(zs)
x_smooth = np.array(fls.xSmooth)[:, 0]


fls_res = abs(x_smooth - nom)
kf_res = abs(kf_x[:, 0] - nom)

plt.plot(zs,'o', alpha=0.5, label='zs')
plt.plot(x_smooth, label='FLS')
plt.plot(kf_x[:, 0], label='KF', ls='--')
plt.legend(loc=4)

print(f'standard deviation fixed-lag: {np.mean(fls_res):.3f}')
print(f'standard deviation kalman: {np.mean(kf_res):.3f}')
```

在这里，我设置了 `N=8`，这意味着我们将把 8 个未来的测量值融合到我们的估计中。一旦滤波器收敛，这为我们提供了一个非常平滑的估计，代价是标准卡尔曼滤波器计算量的大约 8 倍。可以随意尝试更大和更小的 `N` 值。我选择 8 有点随意，不是出于任何理论考虑。
