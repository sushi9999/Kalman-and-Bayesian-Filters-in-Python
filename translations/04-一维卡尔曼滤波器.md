既然我们已经理解了离散贝叶斯滤波器和高斯分布，那么就可以实现卡尔曼滤波器了。我们将以与离散贝叶斯滤波器完全相同的方式来做这件事——不是从方程开始，而是基于对问题的推理逐步开发代码。

"一维"意味着该滤波器只跟踪一个状态变量，例如 x 轴上的位置。在后续章节中，我们将学习更通用的多维形式，它可以同时跟踪许多状态变量，例如位置、速度和加速度。回想一下，我们在 g-h 滤波器中使用了速度，从而获得了比仅跟踪位置更好的估计。卡尔曼滤波器同样如此。

那么为什么不直接进入滤波器的多维形式呢？说实话，数学上很困难，并且我开发滤波器的直观方法开始失效。这些数学会掩盖让卡尔曼滤波器工作的相当简单的原理。

因此，在本章中我们学习如何使用高斯分布来实现一个贝叶斯滤波器。这就是卡尔曼滤波器的全部——一个使用高斯分布的贝叶斯滤波器。在下一章中，我们将切换到多维形式，并释放卡尔曼滤波器的全部威力！

## 问题描述

正如**离散贝叶斯滤波器**章节中那样，我们将跟踪一个在工作场所长走廊里移动的物体。假设在我们最近的一次黑客马拉松中，有人创建了一个 RFID 跟踪器，它能提供狗的合理准确位置。该传感器返回狗距走廊左端的距离（以米为单位）。所以，23.4 表示狗距走廊左端 23.4 米。

该传感器并不完美。读数 23.4 可能对应于狗在 23.7 或 23.0 处。然而，它非常不太可能对应于 47.6 这样的位置。黑客马拉松期间的测试证实了这一结果——传感器是"合理"准确的，虽然有误差，但误差很小。此外，误差似乎在真实位置的两侧均匀分布；位置 23 米处同样可能被测量为 22.9 或 23.1。也许我们可以用高斯分布来建模。

我们预测狗在移动。这种预测并不完美。有时我们的预测会超调，有时会欠调。我们更可能少量超调或欠调，而不是大量超调或欠调。也许我们也可以用高斯分布来建模。

## 信念表示为高斯分布

我们可以用高斯分布来表达对狗位置的信念。比如我们认为狗在 10 米处，并且该信念的方差为 1 m$^2$，即 $\mathcal{N}(10,\, 1)$。其概率密度函数（pdf）的图形如下：

```python
import filterpy.stats as stats
stats.plot_gaussian_pdf(mean=10., variance=1.,
                        xlim=(4, 16), ylim=(0, .5));
```

该图描绘了我们对狗位置的不确定性。它代表了一个相当不精确的信念。虽然我们认为狗最有可能在 10 m 处，但 9 m 到 11 m 之间的任何位置也都很有可能。假设狗站着不动，我们再次查询传感器。这次它返回 10.2 m。我们能用这个额外的信息来改进估计吗？

直觉表明可以。考虑：如果我们读取传感器 500 次，每次都返回一个 8 到 12 之间的值，全部围绕 10，我们就应当非常确信狗在 10 附近。当然，另一种解释也是可能的。也许我们的狗在以一种恰好模拟从正态分布中随机抽取的方式来回随机游走。但这看起来极不可能——我从未见过狗会这样做。让我们看看从 $\mathcal N(10, 1)$ 中抽取的 500 次：

```python
import numpy as np
from numpy.random import randn
import matplotlib.pyplot as plt

xs = range(500)
ys = randn(500)*1. + 10.
plt.plot(xs, ys)
print(f'Mean of readings is {np.mean(ys):.3f}')
```

目测结果证实了我们的直觉——没有狗会这样移动。然而，带噪声的传感器数据当然看起来就是这样。计算得到的读数均值几乎正好是 10。假设狗站着不动，我们说狗在位置 10 处，方差为 1。

## 用高斯概率进行跟踪

离散贝叶斯滤波器使用概率直方图来跟踪狗。直方图中的每个区间代表一个位置，其值是狗处于该位置的概率。

跟踪是通过预测和更新的循环来执行的。我们使用方程

$$\begin{aligned}
\bar {\mathbf x} &= \mathbf x \ast f_{\mathbf x}(\bullet)\, \, &\text{Predict} \\
\mathbf x &= \mathcal L \cdot \bar{\mathbf x}\, \, &\text{Update}
\end{aligned}$$

来计算新的概率分布。回想一下 $\bar{\mathbf x}$ 是*先验（prior）*，$\mathcal L$ 是给定先验 $\bar{\mathbf x}$ 时测量值的*似然（likelihood）*，$f_{\mathbf x}(\bullet)$ 是*过程模型（process model）*，$\ast$ 表示*卷积（convolution）*。$\mathbf x$ 加粗表示它是一个数字直方图，或者说一个向量。

这种方法可行，但导致直方图暗示狗可能同时处于多个位置。此外，对于大型问题计算非常缓慢。

我们能用高斯分布 $\mathcal N(x, \sigma^2)$ 替换直方图 $\mathbf x$ 吗？当然可以！我们已经学会如何将信念表示为高斯分布。一个高斯分布——它只是一对数字 $\mathcal N(\mu, \sigma^2)$——可以替换整个概率直方图：

```python
import kf_book.kf_internal as kf_internal
kf_internal.gaussian_vs_histogram()
```

我希望你看到了这其中的威力。我们可以用一对数字 $x = \mathcal N(\mu, \sigma^2)$ 替换数百到数千个数字。

高斯分布的尾部向两侧延伸到无穷远，因此它包含了直方图中任意多的条形。如果这代表我们对走廊中狗位置的信念，那么这一个高斯分布覆盖了整个走廊（以及该轴上的整个宇宙）。我们认为狗很可能在 10 处，但他也可能在 8、14，或者以无穷小的概率在 10$^{80}$ 处。

在本章中，我们用高斯分布替换直方图：

$$\begin{array}{l|l|c}
\text{discrete Bayes} & \text{Gaussian} & \text{Step}\\
\hline
\bar {\mathbf x} = \mathbf x \ast f(\mathbf x) &
\bar {x}_\mathcal{N} =  x_\mathcal{N} \, \oplus \, f_{x_\mathcal{N}}(\bullet) &
\text{Predict} \\
\mathbf x = \|\mathcal L \bar{\mathbf x}\| & x_\mathcal{N} = L \, \otimes \, \bar{x}_\mathcal{N} & \text{Update}
\end{array}$$

其中 $\oplus$ 和 $\otimes$ 表示对高斯分布进行的某个未知运算符。我在本书后续不会这样做，但下标表明 $x_\mathcal{N}$ 是一个高斯分布。

离散贝叶斯滤波器使用卷积来进行预测。我们已经表明它使用了*全概率定理（total probability theorem）*，以求和的方式计算，所以也许我们可以将高斯分布相加。它使用乘法将测量结果合并到先验中，所以也许我们可以将高斯分布相乘。会这么简单吗：

$$\begin{aligned}
\bar x &\stackrel{?}{=} x + f_x(\bullet) \\
x &\stackrel{?}{=} \mathcal L \cdot \bar x
\end{aligned}$$

这只有在两个高斯分布的和与积仍然是高斯分布时才有效。否则在第一个时间步之后 $x$ 就不再是高斯分布，这个方案也就崩溃了。

## 用高斯分布进行预测

我们使用牛顿运动方程根据当前速度和先前位置计算当前位置：

$$ \begin{aligned}\bar{x}_k &= x_{k-1} + v_k \Delta t \\
 &= x_{k-1} + f_x\end{aligned}$$

我已将记号 $f_x(\bullet)$ 简写为 $f_x$ 以保持方程整洁。

如果狗在 10 m 处，速度为 15 m/s，时间步长为 2 秒，那么我们有

$$ \begin{aligned} f_x &= v\Delta t = 15\cdot 2\\
\bar{x}_k &= 10 + (15\cdot 2) = 40 \end{aligned}$$

我们对其当前位置和速度都不确定，因此这种做法行不通。我们需要用高斯分布来表达不确定性。

位置很简单。我们将 $x$ 定义为高斯分布。如果我们认为狗在 10 m 处，且不确定性的标准差为 0.2 m，则得到 $x=\mathcal N(10, 0.2^2)$。

那么我们对其运动的不确定性呢？我们将 $f_x$ 定义为高斯分布。如果狗的速度为 15 m/s，时间步长为 1 秒，且不确定性的标准差为 0.7 m/s，则得到 $f_x = \mathcal N (15, 0.7^2)$。

先验的方程为

$$\bar x = x + f_x$$

两个高斯分布的和是什么？在上一章中我证明了：

$$\begin{gathered}
\mu = \mu_1 + \mu_2 \\
\sigma^2 = \sigma^2_1 + \sigma^2_2
\end{gathered}$$

这是绝佳的消息；两个高斯分布的和仍是一个高斯分布！

数学上行得通，但这在直觉上说得通吗？想想这个抽象方程的物理表示。我们有

$$\begin{gathered}
x=\mathcal N(10, 0.2^2)\\
f_x = \mathcal N (15, 0.7^2)
\end{gathered}$$

如果我们把它们相加得到：

$$\begin{aligned}\bar x &= \mu_x + \mu_{f_x} = 10 + 15 &&= 25 \\
\bar\sigma^2 &= \sigma_x^2 + \sigma_{f_x}^2 = 0.2^2 + 0.7^2 &&= 0.53\end{aligned}$$

预测位置是先前位置加上运动量，这说得通。那方差呢？要对此形成直觉更困难。然而，回想一下离散贝叶斯滤波器的 `predict()` 函数，我们总是会丢失信息。我们并不真正知道狗在如何移动，因此置信度应该变小（方差变大）。$\sigma_{f_x}^2$ 是由于运动预测不完美而添加到系统中的不确定性量，因此我们将其加到现有的不确定性上。

让我们利用 Python `collection` 模块中的 `namedtuple` 类来实现一个高斯对象。我们也可以用元组实现高斯分布，将 $\mathcal N(10, 0.04)$ 在 Python 中实现为 `g = (10., 0.04)`。我们用 `g[0]` 访问均值，用 `g[1]` 访问方差。

`namedtuple` 与元组工作方式相同，只是你可以为它提供类型名称和字段名称。理解这个并不重要，但我修改了 `__repr__` 方法，使其使用本章的记号显示其值。

```python
from collections import namedtuple
gaussian = namedtuple('Gaussian', ['mean', 'var'])
gaussian.__repr__ = lambda s: f'𝒩(μ={s[0]:.3f}, 𝜎²={s[1]:.3f})'
```

现在我们可以这样创建并打印一个高斯分布：

```python
g1 = gaussian(3.4, 10.1)
g2 = gaussian(mean=4.5, var=0.2**2)
print(g1)
print(g2)
```

```
𝒩(μ=3.400, 𝜎²=10.100)
𝒩(μ=4.500, 𝜎²=0.040)
```

我们可以使用下标或字段名称访问均值和方差：

```python
g1.mean, g1[0], g1[1], g1.var
```

```
(3.4, 3.4, 10.1, 10.1)
```

这是我们 predict 函数的实现，其中 `pos` 和 `movement` 是形式为 ($\mu$, $\sigma^2$) 的高斯元组：

```python
def predict(pos, movement):
    return gaussian(pos.mean + movement.mean, pos.var + movement.var)
```

让我们测试一下。如果初始位置是高斯 $\mathcal N(10, 0.2^2)$，运动是高斯 $\mathcal N (15, 0.7^2)$，那么先验是什么？

```python
pos = gaussian(10., .2**2)
move = gaussian(15., .7**2)
predict(pos, move)
```

```
𝒩(μ=25.000, 𝜎²=0.530)
```

先验表明狗在 25 m 处，方差为 0.53 m$^2$，这与我们手工计算的结果一致。

## 用高斯分布进行更新

离散贝叶斯滤波器在概率直方图中编码我们对狗位置的信念。该分布是离散的且多峰的。它能够同时表达狗位于两个位置的强烈信念，且这些位置是离散的。

我们提议用高斯分布替换直方图。离散贝叶斯滤波器使用以下代码计算后验：

```python
def update(likelihood, prior):
    posterior = likelihood * prior
    return normalize(posterior)
```

这是方程：

$$x = \| \mathcal L\bar x \|$$

的实现。

我们刚刚展示了可以用高斯分布表示先验。那么似然呢？似然是给定当前状态时测量值的概率。我们已经学过如何将测量值表示为高斯分布。例如，也许我们的传感器声明狗在 23 m 处，标准差为 0.4 米。我们的测量值，以似然形式表示，是 $z = \mathcal N (23, 0.16)$。

似然和先验都用高斯分布建模。我们能将高斯分布相乘吗？两个高斯分布的乘积仍是高斯分布吗？

前者答案是肯定的，后者几乎是肯定的！在上一章中我证明了两个高斯分布的乘积与另一个高斯分布成正比。

$$\begin{aligned}
\mu &= \frac{\sigma_1^2 \mu_2 + \sigma_2^2 \mu_1} {\sigma_1^2 + \sigma_2^2}, \\
\sigma^2 &= \frac{\sigma_1^2\sigma_2^2}{\sigma_1^2+\sigma_2^2}
\end{aligned}$$

我们可以立即推断出几件事。如果我们对结果进行归一化，那么乘积仍是一个高斯分布。如果一个高斯分布是似然，第二个是先验，那么均值是先验和测量值的加权和。方差是先验和测量值方差的组合。最后，方差完全不受均值的影响！

我们用贝叶斯术语将其表述为：

$$\begin{aligned}
\mathcal N(\mu, \sigma^2) &= \| prior \cdot likelihood \|\\
&= \| \mathcal{N}(\bar\mu, \bar\sigma^2)\cdot \mathcal{N}(\mu_z, \sigma_z^2) \|\\
&= \mathcal N(\frac{\bar\sigma^2 \mu_z + \sigma_z^2 \bar\mu}{\bar\sigma^2 + \sigma_z^2},\frac{\bar\sigma^2\sigma_z^2}{\bar\sigma^2 + \sigma_z^2})
\end{aligned}$$

如果我们在一个 `gaussian_multiply()` 函数中实现这一点，我们就可以将滤波器的更新步骤实现为：

```python
def gaussian_multiply(g1, g2):
    mean = (g1.var * g2.mean + g2.var * g1.mean) / (g1.var + g2.var)
    variance = (g1.var * g2.var) / (g1.var + g2.var)
    return gaussian(mean, variance)

def update(prior, likelihood):
    posterior = gaussian_multiply(likelihood, prior)
    return posterior

# test the update function
predicted_pos = gaussian(10., .2**2)
measured_pos = gaussian(11., .1**2)
estimated_pos = update(predicted_pos, measured_pos)
estimated_pos
```

```
𝒩(μ=10.800, 𝜎²=0.008)
```

如果我们使用更具体的名称，也许会更清楚：

```python
def update_dog(dog_pos, measurement):
    estimated_pos = gaussian_multiply(measurement, dog_pos)
    return estimated_pos
```

这不那么抽象，或许有助于理解，但这是糟糕的编码实践。我们正在编写一个适用于任何问题的卡尔曼滤波器，而不仅仅是跟踪走廊里的狗，因此我们不会使用包含 'dog' 的变量名。此外，这种形式掩盖了我们正在用先验乘以似然这一事实。

我们已经实现了滤波器的大部分内容，但我担心这一步还是有点令人困惑。我断言我们可以将高斯分布相乘，并且这正确地执行了更新步骤，但为什么这是真的？让我们绕个弯，花些时间来研究高斯分布的乘法。

### 理解高斯乘法

让我们绘制 $\mathcal{N}(10,\, 1) \times \mathcal{N}(10,\, 1)$ 的概率密度函数。你能在不看结果的情况下确定它的形状吗？新的均值应该是多少？曲线会比 $\mathcal{N}(10,\, 1)$ 更宽、更窄，还是相同？

```python
z = gaussian(10., 1.)  # Gaussian N(10, 1)

product = gaussian_multiply(z, z)

xs = np.arange(5, 15, 0.1)
ys = [stats.gaussian(x, z.mean, z.var) for x in xs]
plt.plot(xs, ys, label='$\mathcal{N}(10,1)$')

ys = [stats.gaussian(x, product.mean, product.var) for x in xs]
plt.plot(xs, ys, label='$\mathcal{N}(10,1) \\times \mathcal{N}(10,1)$', ls='--')
plt.legend()
print(product)
```

乘积结果比原始高斯分布更高更窄，但均值不变。这是否符合你的直觉？

将两个高斯分布想象成两次测量。如果我测量两次都得到 10 米，我应该得出长度接近 10 米的结论。因此均值应为 10。得出长度实际为 11 或 9.5 是没有道理的。此外，与一次测量相比，我对两次测量更有信心，因此结果的方差应该更小。

"量两次，切一次"是一句众所周知的谚语。高斯乘法是这一物理事实的数学模型。

我不太可能连续两次得到相同的测量值。现在让我们绘制 $\mathcal{N}(10.2,\, 1) \times \mathcal{N}(9.7,\, 1)$ 的概率密度函数。你认为结果会是什么？想一想，然后看图。

```python
m = 3.3
f'$({m},{m})$'
```

```
'$(3.3,3.3)$'
```

```python
def plot_products(g1, g2):
    plt.figure()
    product = gaussian_multiply(g1, g2)

    xs = np.arange(5, 15, 0.1)
    ys = [stats.gaussian(x, g1.mean, g1.var) for x in xs]
    plt.plot(xs, ys, label='$\mathcal{N}$' + f'$({g1.mean},{g1.var})$')

    ys = [stats.gaussian(x, g2.mean, g2.var) for x in xs]
    plt.plot(xs, ys, label='$\mathcal{N}$' + '$({g2.mean},{ge.var})$')

    ys = [stats.gaussian(x, product.mean, product.var) for x in xs]
    plt.plot(xs, ys, label='product', ls='--')
    plt.legend();
    plt.show()

z1 = gaussian(10.2, 1)
z2 = gaussian(9.7, 1)

plot_products(z1, z2)
```

如果你让两个人测量桌子距墙壁的距离，一个人得到 10.2 米，另一个人得到 9.7 米，假如你同等信任两人的能力，你最好的猜测必然是平均值，即 9.95 米。

回想一下 g-h 滤波器。我们一致认为，如果我在两个秤上称体重，第一个读数为 160 磅，第二个读数为 170 磅，且两者同样准确，则最佳估计为 165 磅。此外，相比于 160 磅或 170 磅，我应该对 165 磅更有信心，因为我现在有两个读数，都接近这个估计值，这增加了我对两者都不会大错的信心。

在更复杂的情况下，这变得反直觉，所以让我们进一步思考。也许更合理的假设是其中一个人犯了错误，真实距离要么是 10.2，要么是 9.7，但绝对不是 9.95。这当然是可能的。但我们知道我们有带噪声的测量值，因此我们没有理由认为某个测量值没有噪声，或者某个人犯了大错以至于我们可以丢弃他的测量值。考虑到所有可用信息，最佳估计必然是 9.95。

在卡尔曼滤波器的更新步骤中，我们组合的不是两个测量值，而是一个测量值和先验，即合并测量值之前的估计。我们针对 g-h 滤波器经历过这个逻辑。无论是合并来自两个测量值的信息，还是合并测量值与预测值，数学是相同的。

让我们看看这一点。我将创建一个相当不准确的先验 $\mathcal N(8.5, 1.5)$ 和一个更准确的测量值 $\mathcal N(10.2, 0.5)$。所谓"准确"，我的意思是传感器方差小于先验方差，而不是说我以某种方式知道狗更接近 10.2 而非 8.5。接下来我将绘制相反的关系：一个准确的先验 $\mathcal N(8.5, 0.5)$ 和一个不准确的测量值 $\mathcal N(10.2, 1.5)$。

```python
prior, z = gaussian(8.5, 1.5), gaussian(10.2, 0.5)
plot_products(prior, z)

prior, z = gaussian(8.5, 0.5), gaussian(10.2, 1.5)
plot_products(prior, z)
```

结果是一个比任一输入都更高的高斯分布。这说得通——我们合并了信息，所以方差应该减少。并且注意，结果远更接近方差较小的输入。我们对该值更有信心，因此对其加权更重是合理的。

它*似乎*有效，但真的正确吗？关于这一点还有更多要说，但我想先让一个可工作的滤波器运行起来，让你能以具体的方式体验它。之后我们将重新讨论高斯乘法并确定为何它是正确的。

## 代码演练

现在让我们演练代码。


这些是过程模型和传感器的方差。传感器方差的含义应该很清楚——它是每次测量中有多少方差。过程方差是过程模型中有多少误差。我们预测在每个时间步狗向前移动 1 米。狗很少做我们期望的事，山丘或松鼠的气味等事情会改变它的进度。如果这是一个响应数字命令的机器人，性能会好得多，方差可能是 $\sigma^2=.05$。这些不是"魔法"数字；方差的平方根是以米为单位的距离误差。通过简单地插入数字很容易让卡尔曼滤波器工作，但如果这些数字不反映现实，滤波器的性能将会很差。

## 卡尔曼增益

我们看到滤波器有效。现在让我们回到数学来理解正在发生的事情。后验 $x$ 计算为似然乘以先验（$\mathcal L \bar x$），其中两者都是高斯分布。

因此后验的均值由以下给出：

$$
\mu=\frac{\bar\sigma^2\, \mu_z + \sigma_z^2 \, \bar\mu} {\bar\sigma^2 + \sigma_z^2}
$$

我使用下标 $z$ 表示测量值。我们可以将其重写为：

$$\mu = \left( \frac{\bar\sigma^2}{\bar\sigma^2 + \sigma_z^2}\right) \mu_z + \left(\frac{\sigma_z^2}{\bar\sigma^2 + \sigma_z^2}\right)\bar\mu$$

在这种形式下，很容易看出我们正在用权重缩放测量值和先验：

$$\mu = W_1 \mu_z + W_2 \bar\mu$$

权重之和为 1，因为分母是归一化项。我们引入一个新术语，$K=W_1$，给出：

$$\begin{aligned}
\mu &= K \mu_z + (1-K) \bar\mu\\
&= \bar\mu + K(\mu_z - \bar\mu)
\end{aligned}$$

其中

$$K = \frac {\bar\sigma^2}{\bar\sigma^2 + \sigma_z^2}$$

$K$ 是*卡尔曼增益（Kalman gain）*。它是卡尔曼滤波器的关键。它是一个缩放项，选择介于 $\mu_z$ 和 $\bar\mu$ 之间的值。

让我们做几个例子。如果测量值比先验准确九倍，那么 $\bar\sigma^2 = 9\sigma_z^2$，并且

$$\begin{aligned}
\mu&=\frac{9 \sigma_z^2 \mu_z + \sigma_z^2\, \bar\mu} {9 \sigma_z^2 + \sigma_\mathtt{z}^2} \\
&= \left(\frac{9}{10}\right) \mu_z + \left(\frac{1}{10}\right) \bar\mu
\end{aligned}
$$

因此 $K = \frac 9 {10}$，为了形成后验，我们取测量值的十分之九和先验的十分之一。

如果测量值和先验同样准确，那么 $\bar\sigma^2 = \sigma_z^2$ 并且

$$\begin{gathered}
\mu=\frac{\sigma_z^2\,  (\bar\mu + \mu_z)}{2\sigma_\mathtt{z}^2} \\
= \left(\frac{1}{2}\right)\bar\mu + \left(\frac{1}{2}\right)\mu_z
\end{gathered}$$

这是两个均值的平均值。取两个同样准确值的平均值在直觉上是合理的。

我们也可以用卡尔曼增益来表达方差：

$$\begin{aligned}
\sigma^2 &= \frac{\bar\sigma^2 \sigma_z^2 } {\bar\sigma^2 + \sigma_z^2} \\
&= K\sigma_z^2 \\
&= (1-K)\bar\sigma^2 
\end{aligned}$$

我们可以通过查看此图来理解这一点：

```python
import kf_book.book_plots as book_plots
book_plots.show_residual_chart()
```

卡尔曼增益 $K$ 是一个缩放因子，它沿残差选择一个值。这导致 `update()` 和 `predict()` 的另一种但等效的实现：

```python
def update(prior, measurement):
    x, P = prior        # mean and variance of prior
    z, R = measurement  # mean and variance of measurement
    
    y = z - x        # residual
    K = P / (P + R)  # Kalman gain

    x = x + K*y      # posterior
    P = (1 - K) * P  # posterior variance
    return gaussian(x, P)

def predict(posterior, movement):
    x, P = posterior # mean and variance of posterior
    dx, Q = movement # mean and variance of movement
    x = x + dx
    P = P + Q
    return gaussian(x, P)
```

我为什么这样写，为什么我选择了这些糟糕的变量名？有几个相关的原因。大多数书籍和论文以这种形式呈现卡尔曼滤波器。我从贝叶斯原理推导滤波器并非不为人知，但使用频率远不如此。替代推导自然导致这种形式的方程。此外，多元卡尔曼滤波器的方程看起来几乎与这些方程完全一样。因此，你需要学习和理解它们。

名称 `z`、`P`、`Q` 和 `R` 从哪里来？你将在本书其余部分看到它们被使用。在文献中，$R$ 几乎普遍用于测量噪声，$Q$ 用于过程噪声，$P$ 用于状态的方差。使用 $z$ 表示测量值很常见，尽管不是普遍的。你读到的几乎每本书和论文都会使用这些变量名。习惯它们。

这也是思考滤波的强大方式。这是我们对 g-h 滤波器推理的方式。它强调取残差 $y = \mu_z - \bar\mu$，找到卡尔曼增益作为我们对先验和测量值不确定性的比率 $K = P/(P+R)$，并通过将 $Ky$ 加到先验上来计算后验。

贝叶斯方面在这种形式中被掩盖了，似然乘以先验这一事实也是如此。两种观点是等价的，因为数学是相同的。我选择贝叶斯方法是因为我认为它对概率推理提供了更直观但更深入的理解。使用 $K$ 的这种替代形式对所谓的*正交投影（orthogonal projection）*方法提供了深入的理解。卡尔曼博士在发明这个滤波器时使用了那种推导，而不是贝叶斯推理。你将在接下来的几章中更多地了解这一点。

## 算法的完整描述

回想一下我们用于 g-h 滤波器的图：

<img src="./figs/residual_chart.png">

在本章中我们一直在做同样的事情。卡尔曼滤波器进行预测，进行测量，然后在两者之间形成新的估计。

**这一点极其重要要理解**：本书中的每个滤波器都实现相同的算法，只是数学细节不同。后续章节中数学可能变得具有挑战性，但思想很容易理解。

重要的是要看穿特定滤波器方程的细节，并理解这些方程在计算*什么*以及*为什么*。滤波器数量极多。它们都使用不同的数学来实现相同的算法。数学的选择影响结果的质量和可表示的问题，但不影响基本思想。

这是通用算法：

**初始化**

    1. 初始化滤波器的状态
    2. 初始化我们对状态的信念

**预测**

    1. 使用系统行为预测下一个时间步的状态
    2. 调整信念以反映预测中的不确定性

**更新**

    1. 获取测量值及其关于准确性的相关信念
    2. 计算估计状态与测量值之间的残差
    3. 根据测量值或预测哪个更准确来计算缩放因子
    4. 根据缩放因子在预测和测量之间设定状态
    5. 根据我们对测量的确信程度更新对状态的信念

你很难找到一个不符合这种形式的贝叶斯滤波器算法。一些滤波器不会包含某些方面，例如预测中的误差，而其他滤波器会有非常复杂的计算方法，但这就是它们都做的事。

一维卡尔曼滤波器的方程是：

<u>预测</u>

$\begin{array}{|l|l|l|}
\hline
\text{方程} & \text{实现} & \text{卡尔曼形式}\\
\hline
 \bar x = x + f_x & \bar\mu = \mu + \mu_{f_x} & \bar x = x + dx\\
& \bar\sigma^2 = \sigma^2 + \sigma_{f_x}^2 & \bar P = P + Q\\
\hline
\end{array}$


<u>更新</u>

$\begin{array}{|l|l|l|}
\hline
\text{方程} & \text{实现}& \text{卡尔曼形式}\\
\hline
 x = \| \mathcal L\bar x\| & y = z - \bar\mu & y = z - \bar x\\
 & K = \frac {\bar\sigma^2} {\bar\sigma^2 + \sigma_z^2} & K = \frac {\bar P}{\bar P+R}\\
 & \mu = \bar \mu + Ky & x = \bar x + Ky\\
 & \sigma^2 = \frac {\bar\sigma^2 \sigma_z^2} {\bar\sigma^2 + \sigma_z^2} & P = (1-K)\bar P\\
\hline
\end{array}$

## 与 g-h 和离散贝叶斯滤波器的比较

现在是从我们如何建模误差的角度来理解这三个滤波器之间差异的好时机。对于 g-h 滤波器，我们如此图所示对测量值建模：

```python
book_plots.plot_errorbars([(160, 3, 'A'), (170, 9, 'B')], xlims=(150, 180))
```

传感器 A 返回测量值 160，传感器 B 返回 170。这些条形是[*误差棒（error bars）*](https://en.wikipedia.org/wiki/Error_bar)——它们说明了测量的可能误差范围。因此，A 测量的实际值可以在 157 到 163 之间，B 测量的值在 161 到 179 之间。

我当时没有定义它，但这是一个[*均匀分布（uniform distribution）*](https://en.wikipedia.org/wiki/Uniform_distribution_(continuous))。均匀分布将相同的概率分配给范围内的任何事件。根据这个模型，传感器 A 读取 157、160 或 163 的概率是相等的。这些范围之外的任何值的概率为 0。

我们可以用高斯分布对这种情况建模。我将对传感器 A 使用 $\mathcal{N}(160, 3^2)$，对传感器 B 使用 $\mathcal{N}(170, 9^2)$。我已在下方与均匀分布误差棒一起绘制了它们以进行比较。

```python
xs = np.arange(145, 190, 0.1)
ys = [stats.gaussian(x, 160, 3**2) for x in xs]
plt.plot(xs, ys, label='A', color='g')

ys = [stats.gaussian(x, 170, 9**2) for x in xs]
plt.plot(xs, ys, label='B', color='b')
plt.legend();
plt.errorbar(160, [0.04], xerr=[3], fmt='o', color='g', capthick=2, capsize=10)
plt.errorbar(170, [0.015], xerr=[9], fmt='o', color='b', capthick=2, capsize=10);
```

使用均匀分布或高斯分布是建模选择。两者都没有完全描述现实。在大多数情况下，高斯分布更现实。大多数传感器更可能返回接近被测量值的读数，而不太可能返回远离该值的读数。高斯分布对这种倾向建模。相比之下，均匀分布假设范围内的任何测量值都同样可能。

现在让我们看看离散贝叶斯滤波器中使用的*离散分布（discrete distribution）*。这个模型将可能值的范围划分为离散范围，并为每个桶分配一个概率。只要概率之和为 1，这种分配可以完全任意。

让我们用均匀分布、高斯分布和离散分布绘制一个传感器的数据。

```python
from random import random
xs = np.arange(145, 190, 0.1)
ys = [stats.gaussian(x, 160, 3**2) for x in xs]
belief = np.array([random() for _ in range(40)])
belief = belief / sum(belief)

x = np.linspace(155, 165, len(belief))
plt.gca().bar(x, belief, width=0.2)
plt.plot(xs, ys, label='A', color='g')
plt.errorbar(160, [0.04], xerr=[3], fmt='o', color='k', capthick=2, capsize=10)
plt.xlim(150, 170);
```

我使用随机数形成离散分布，以说明它可以建模任意概率分布。这赋予了它巨大的能力。有足够的离散桶，我们可以建模任何传感器的误差特性，无论多么复杂。但这种能力伴随着数学上的难处理性。乘以或加上高斯分布需要两行数学，结果是另一个高斯分布。这种规律性允许我们对滤波器的性能和行为执行强大的分析。乘以或加上离散分布需要遍历数据，我们没有简单的方法来描述结果。基于离散分布分析滤波器的性能特性极其困难甚至不可能。

这里没有"正确"的选择。在本书后面我们将介绍使用离散分布的*粒子滤波器（particle filter）*。它是一种极其强大的技术，因为它可以处理任意复杂的情况。代价是性能慢，并且对解析分析的抵抗力。

目前我们将忽略这些问题，并在接下来的几章中回到使用高斯分布。随着我们的进展，你将了解在我们的数学模型中使用高斯分布的优势和局限性。

## 设计滤波器简介

到目前为止，我们已经为位置传感器开发了滤波器。我们现在已经习惯了这个问题，并且可能感觉无法为不同问题实现卡尔曼滤波器。说实话，本演示中仍然缺少相当多的信息。后续章节将填补空白。不过，让我们通过设计和实现一个温度计的卡尔曼滤波器来感受一下。温度计的传感器输出对应于被测温度的电压。我们已经阅读了传感器的制造商规格，它告诉我们传感器表现出标准差为 0.13 伏特的白噪声。

我们可以用这个函数模拟温度传感器测量：

```python
def volt(voltage, std):
    return voltage + (randn() * std)
```

现在我们需要编写卡尔曼滤波器的处理循环。与之前的问题一样，我们需要执行预测和更新的循环。感测步骤可能看起来很清楚——调用 `volt()` 获取测量值，将结果传递给 `update()` 方法，但预测步骤呢？我们没有传感器来检测电压的"运动"，并且对于任何短的持续时间，我们期望电压保持不变。我们应该如何处理这个？

一如既往，我们将相信数学。我们没有已知的运动，所以我们将其设为零。然而，这意味着我们预测温度永远不会改变。如果这是真的，那么随着时间的推移，我们应该对结果非常有信心。一旦滤波器有足够的测量值，它将变得非常确信它可以预测后续温度，这将导致它忽略由于实际温度变化而产生的测量值。这被称为*自满（smug）*滤波器，是你想要避免的事情。所以我们将向预测步骤添加一点误差，告诉滤波器不要随着时间的推移忽略电压的变化。在下面的代码中，我设置 `process_var = .05**2`。这是每个时间步内电压变化的预期方差。我选择这个值仅仅是为了能够展示方差如何通过更新和预测步骤变化。对于真实的传感器，你会根据实际期望的变化量来设置这个值。例如，如果这是用于房屋内环境空气温度的温度计，这将是一个极小的数字，如果这是化学反应室中的热电偶，则是一个高数字。我们将在后面的章节中更多地讨论选择实际值。

让我们看看会发生什么。

```python
temp_change = 0
voltage_std = .13
process_var = .05**2
actual_voltage = 16.3

x = gaussian(25., 1000.) # initial state
process_model = gaussian(0., process_var)

N = 50
zs = [volt(actual_voltage, voltage_std) for i in range(N)]
ps = []
estimates = []

for z in zs:
    prior = predict(x, process_model)
    x = update(prior, gaussian(z, voltage_std**2))

    # save for latter plotting
    estimates.append(x.mean)
    ps.append(x.var)

# plot the filter output and the variance
book_plots.plot_measurements(zs)
book_plots.plot_filter(estimates, var=np.array(ps))
book_plots.show_legend()
plt.ylim(16, 17)
book_plots.set_labels(x='step', y='volts')
plt.show()

plt.plot(ps)
plt.title('Variance')
print(f'Variance converges to {ps[-1]:.3f}')
```

第一个图显示了单独的传感器测量值与滤波器输出。尽管传感器中有大量噪声，我们很快发现了传感器的近似电压。在我撰写时刚刚完成的运行中，滤波器的最后电压输出是 $16.213$，这非常接近 `volt()` 函数使用的 $16.4$。在其他运行中，我得到了更大和更小的结果。

规格表正如听起来那样——规格。任何单独的传感器都会因正常制造差异而表现出不同的性能。值通常是最大值——规格保证性能至少这么好。如果你购买昂贵的设备，通常会附带一张纸，显示你具体物品的测试结果；这通常非常可信。另一方面，如果这是一个便宜的传感器，它在销售前可能很少或根本没有经过测试。制造商通常测试其产出的一小部分以验证样本是否落在所需的性能范围内。如果你有关键应用，你需要仔细阅读规格表以弄清楚他们对其范围的确切含义。他们保证他们的数字是最大值，还是说，$3\sigma$ 错误率？是否每个物品都经过测试？方差是正态的还是其他分布？最后，制造并不完美。你的部件可能有缺陷，并且与规格表上的性能不匹配。

例如，我正在查看气流传感器的数据表。有一个字段*重复性（Repeatability）*，值为 $\pm 0.50\%$。这是高斯分布吗？是否有偏差？例如，也许重复性在低温下接近 $0.0\%$，而在高温下总是接近 $+0.50\%$。电气元件的数据表通常包含"典型性能特性"部分。这些用于捕获不能轻易在表中传达的信息。例如，我正在查看一张显示 LM555 计时器的输出电压与电流关系的图表。有三条曲线显示在不同温度下的性能。响应理想上是线性的，但所有三条线都是弯曲的。这表明电压输出中的误差可能不是高斯分布——在该芯片的情况下，更高的温度导致更低的电压输出，并且如果输入电流非常高，电压输出是相当非线性的。

正如你可能猜到的，建模传感器性能是创建表现良好的卡尔曼滤波器的较难部分之一。

## 示例：极端噪声量

对于狗滤波器，我没有在信号中加入大量噪声，并且我"猜测"狗在位置 0。在真实世界条件下滤波器的表现如何？我将开始在 RFID 传感器中注入更多噪声，同时将过程方差保持在 2 m$^2$。我将注入极端的噪声量——显然淹没了实际测量值的噪声。如果传感器的标准差为 300 米，你的直觉对滤波器的性能怎么说？换句话说，实际位置 1.0 m 可能被报告为 287.9 m，或 -589.6 m，或大致在该范围内的任何其他数字。在向下滚动之前先想一想。

```python
sensor_var = 300.**2
process_var = 2.
process_model = gaussian(1., process_var)
pos = gaussian(0., 500.)
N = 1000
dog = DogSimulation(pos.mean, 1., sensor_var, process_var)
zs = [dog.move_and_sense() for _ in range(N)]
ps = []

for i in range(N):
    prior = predict(pos, process_model)
    pos = update(prior, gaussian(zs[i], sensor_var))
    ps.append(pos.mean)

book_plots.plot_measurements(zs, lw=1)
book_plots.plot_filter(ps)
plt.legend(loc=4);
```

在这个例子中，噪声是极端的，但滤波器仍然输出几乎是直线！这是一个惊人的结果！你认为这种性能的原因是什么？

我们得到几乎是直线，因为我们的过程误差很小。小的过程误差告诉滤波器预测非常可信，并且预测是一条直线，所以滤波器输出几乎是直线。

## 示例：不正确的过程方差

最后那个滤波器看起来很棒！为什么我们不将过程方差设置得很低，因为它保证结果将是直的和平滑的？

过程方差告诉滤波器系统随时间变化多少。如果你通过将这个数字人为地设置得很低来欺骗滤波器，滤波器将无法对正在发生的变化做出反应。让我们让狗在每个时间步将其速度增加少量，看看滤波器在过程方差为 0.001 m$^2$ 时的表现。

```python
sensor_var = 20.
process_var = .001
process_model = gaussian(1., process_var)
pos = gaussian(0., 500.)
N = 100
dog = DogSimulation(pos.mean, 1, sensor_var, process_var*10000)
zs, ps = [], []
for _ in range(N):
    dog.velocity += 0.04
    zs.append(dog.move_and_sense())

for z in zs:
    prior = predict(pos, process_model)
    pos = update(prior, gaussian(z, sensor_var))
    ps.append(pos.mean)

book_plots.plot_measurements(zs, lw=1)
book_plots.plot_filter(ps)
plt.legend(loc=4);
```

很容易看出滤波器没有正确响应测量值。测量值清楚地表明狗正在改变速度，但滤波器被告知其预测几乎是完美的，所以它几乎完全忽略它们。我鼓励你调整狗的运动量与过程方差。我们也将在后面的章节中更多地研究这个主题。关键是要认识到数学要求方差正确描述你的系统。滤波器不会"注意"到它正在偏离测量值并自我修正。它根据先验和测量值的方差计算卡尔曼增益，并根据哪个更准确来形成估计。

## 示例：错误的初始估计

现在让我们看看当我们对位置进行错误的初始估计时的结果。为了避免掩盖结果，我将传感器方差减小到 30，但将初始位置设为 1000 米。滤波器能从 1000 米的误差中恢复吗？

```python
sensor_var = 5.**2
process_var = 2.
pos = gaussian(1000., 500.)
process_model = gaussian(1., process_var)
N = 100
dog = DogSimulation(0, 1, sensor_var, process_var)
zs = [dog.move_and_sense() for _ in range(N)]
ps = []

for z in zs:
    prior = predict(pos, process_model)
    pos = update(prior, gaussian(z, sensor_var))
    ps.append(pos.mean)

book_plots.plot_measurements(zs, lw=1)
book_plots.plot_filter(ps)
plt.legend(loc=4);
```

答案再次是肯定的！因为我们对传感器的信念相对确定（$\sigma^2=5^2$），仅在第一步之后我们就将位置估计从 1000 m 改变到大约 50 m。再过 5-10 次测量后，我们已经收敛到正确值。这就是我们如何绕过初始猜测的鸡和蛋问题。在实践中，我们可能会将传感器的第一次测量值分配为初始值，但你可以看到，如果我们对初始条件进行疯狂猜测也无关紧要——只要选择滤波器的方差以匹配实际的过程和测量方差，卡尔曼滤波器仍然会收敛。

## 示例：大噪声和错误的初始估计

两个世界中最坏的呢，大噪声和错误的初始估计？

```python
sensor_var = 30000.
process_var = 2.
pos = gaussian(1000., 500.)
process_model = gaussian(1., process_var)

N = 1000
dog = DogSimulation(0, 1, sensor_var, process_var)

```

这次滤波器陷入困境。注意上一个例子只计算了 100 次更新，而这个例子使用了 1000 次。在我看来，滤波器需要 400 次左右的迭代才能变得相当准确，但可能需要超过 600 次结果才会好。卡尔曼滤波器很好，但我们不能期望奇迹。如果我们有极其嘈杂的数据和极差的初始条件，这就是它能达到的最好水平。

最后，让我们实现使用第一次测量值作为初始位置的建议。

```python
sensor_var = 30000.
process_var = 2.
process_model = gaussian(1., process_var)
N = 1000
dog = DogSimulation(0, 1, sensor_var, process_var)
zs = [dog.move_and_sense() for _ in range(N)]

pos = gaussian(zs[0], 500.)

    prior = predict(pos, process_model)
    pos = update(prior, gaussian(z, sensor_var))

```

这个简单的更改显著改善了结果。在某些运行中需要 200 次左右的迭代才能稳定到一个好的解，但其他运行收敛非常迅速。这一切都取决于第一次测量中的噪声量。大量的噪声导致初始估计远离狗的位置。

200 次迭代似乎很多，但我们注入的噪声量确实是巨大的。在现实世界中，我们使用温度计、激光测距仪、GPS 卫星、计算机视觉等传感器。这些示例中没有一个具有巨大的误差。便宜的温度计的合理方差可能是 0.2 C$^{\circ 2}$，而我们的代码使用的是 30,000 C$^{\circ 2}$。

```python
from numpy.random import seed

def plot_kalman_filter(start_pos,
                       sensor_noise,
                       velocity,
                       process_noise):

    zs, ps = [], []

interact(plot_kalman_filter,
         start_pos=(-10, 10),
         sensor_noise=FloatSlider(value=5, min=0., max=100),
```

## 练习——非线性系统

我们的卡尔曼滤波器方程是线性的：

$$\begin{aligned}
\mathcal{N}(\bar\mu,\, \bar\sigma^2) &= \mathcal{N}(\mu,\, \sigma^2) + \mathcal{N}(\mu_\mathtt{move},\, \sigma^2_\mathtt{move})\\
\mathcal{N}(\mu,\, \sigma^2) &= \mathcal{N}(\bar\mu,\, \bar\sigma^2)  \times \mathcal{N}(\mu_\mathtt{z},\, \sigma^2_\mathtt{z})
\end{aligned}$$

你认为这个滤波器在非线性系统下表现良好还是糟糕？

实现一个使用以下方程生成测量值的卡尔曼滤波器：

```python
for i in range(100):
    z = math.sin(i/3.) * 2
```

调整方差和初始位置以查看效果。例如，非常糟糕的初始猜测的结果是什么？

```python

```

### 解答

```python
import math

sensor_var = 30.
process_var = 2.
pos = gaussian(100., 500.)
process_model = gaussian(1., process_var)

zs, ps = [], []

for i in range(100):
    pos = predict(pos, process_model)

    z = math.sin(i/3.)*2 + randn()*1.2
    zs.append(z)

    pos = update(pos, gaussian(z, sensor_var))
    ps.append(pos.mean)

plt.plot(zs, c='r', linestyle='dashed', label='measurement')
plt.plot(ps, c='#004080', label='filter')
plt.legend(loc='best');
```

### 讨论

这太糟糕了！输出根本不像正弦波，除了非常粗略地。对于线性系统，我们可以向信号中添加极端的噪声量，仍然提取出非常准确的结果，但这里即使是适度的噪声也会产生非常糟糕的结果。

如果我们回想 **g-h 滤波器**章节，我们可以理解这里发生了什么。g-h 滤波器的结构要求滤波器输出选择介于预测和测量之间的值。像这样的变化信号总是在加速，而我们的过程模型假设恒定速度，所以滤波器在数学上保证总是滞后于输入信号。

实践者在开始实现卡尔曼滤波器后不久就认识到它们对非线性系统的较差性能，并开始设计处理它的方法。后续章节专门讨论这个问题。

## 固定增益滤波器

嵌入式计算机通常具有极其有限的处理器。许多没有浮点电路。这些简单的方程会给芯片带来沉重的负担。随着技术的进步，这一点不那么真实了，但当你将购买数百万个时，不要低估在处理器上少花一美元的价值。

在上面的例子中，滤波器的方差收敛到一个固定值。如果测量和过程的方差是常数，这总会发生。你可以利用这一事实，通过运行模拟来确定方差收敛到什么。然后你可以将这个值硬编码到你的滤波器中。只要你将滤波器初始化为良好的起始猜测（我建议使用第一次测量值作为初始值），滤波器就会表现得非常好。例如，狗跟踪滤波器可以简化为：

```python
def update(x, z):
    K = .13232  # experimentally derived Kalman gain
    y = z - x   # residual
    x = x + K*y # posterior
    return x

def predict(x):
    return x + vel*dt
```

我使用了卡尔曼增益形式的更新函数，以强调我们根本不需要考虑方差。如果方差收敛到单个值，卡尔曼增益也是如此。

## FilterPy 的实现

FilterPy 实现了 `predict()` 和 `update()`。它们不仅适用于本章中开发的一维情况，也适用于我们在后续章节中学习的更通用的多元情况。因此，它们的接口略有不同。它们不将高斯作为元组接受，而是作为两个单独命名的变量。

`predict()` 接受几个参数，但我们只需要使用这四个：

```python
predict(x, P, u, Q)
```

`x` 是系统的状态。`P` 是系统的方差。`u` 是过程引起的运动，`Q` 是过程中的噪声。在调用 `predict()` 时需要使用命名参数，因为大多数参数是可选的。`predict()` 的第三个参数**不是** `u`。

这些可能让你觉得是糟糕的变量名。它们就是！正如我已经提到的，它们来自控制理论的悠久历史，你阅读的每篇论文或每本书都会使用这些名称。所以，我们必须习惯它。拒绝记住它们意味着你将永远无法阅读文献。

让我们对状态 $\mathcal N(10, 3)$ 和运动 $\mathcal N(1, 4)$ 进行尝试。我们期望最终位置为 11（10+1），方差为 7（3+4）。

```python
import filterpy.kalman as kf
kf.predict(x=10., P=3., u=1., Q=4.)
```

```
(11.0, 7.0)
```

`update` 也接受几个参数，但目前你将对这四个感兴趣：

```python
update(x, P, z, R)
```

和以前一样，`x` 和 `P` 是系统的状态和方差。`z` 是测量值，`R` 是测量方差。让我们执行最后一个 predict 语句以获得我们的先验，然后执行更新：

```python
x, P = kf.predict(x=10., P=3., u=1., Q=2.**2)
print(f'{x:.3f}')

x, P = kf.update(x=x, P=P, z=12., R=3.5**2)
print(f'{x:.3f} {P:.3f}')
```

```
11.000
11.364 4.455
```

我给了它一个方差很大的有噪声测量值，所以估计仍然接近先验 11。

最后一点。我没有为预测步骤的输出使用变量名 `prior`。在本书的其余部分我也不会使用这个变量名。卡尔曼滤波器方程只使用 $\mathbf x$。先验和后验都是系统的估计状态，前者是合并测量值之前的估计，后者是合并测量值之后的估计。
